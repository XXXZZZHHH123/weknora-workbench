# WeKnora Noto Serif SC — regular weight

Self-hosted from the official Google Fonts CSS API. Complete Unicode ranges are retained; the browser fetches only chunks required by displayed text. No runtime CDN request.

- CSS: https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400&display=swap
- Metadata: https://github.com/google/fonts/blob/main/ofl/notoserifsc/METADATA.pb
- Weight: 400
- License: SIL Open Font License 1.1, included as OFL.txt.
- CSS and source asset hashes: asset-manifest.json.

Registered as the same `WeKnora Noto Serif SC` family as the existing 600 face in `../noto-serif-sc/`. The shared family lets menus, hints, data and reading text select real 400/600 faces by CSS weight without synthesizing bold from the regular face. The directory and asset URLs are retained to reuse cached font files.
