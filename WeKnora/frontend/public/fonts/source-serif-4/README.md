# Source Serif 4 — workspace numerals

Unmodified Adobe Source Serif 4 Roman variable WOFF2, self-hosted for numeric characters in the default workspace font. CSS limits this face to `U+0030-0039`; Chinese and Latin text keep their existing families, and explicit user font choices and monospace/code fonts remain independent. Lining, tabular numerals keep dates, counts and market values aligned.
