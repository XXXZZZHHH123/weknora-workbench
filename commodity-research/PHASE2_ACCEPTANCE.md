# 第二阶段验收记录

验收日期：2026-10-12。本次交付在 WeKnora Workbench 内完成；原 CRP 仓库和生产服务器未改动，服务器仍由 `deploy/update.sh` 手动发布。

## 已交付

1. 商品研究首页提供自动刷新计划、立即更新、单来源更新/重试及运行状态。默认每天北京时间 08:00、16:30，用户可调整或暂停。SHFE 行情、仓单、周库存、CFETS 汇率、CBOE VIX、FRED 共用同一取数流水线，写入共享事实并重算派生指标和确定性信号，无需逐次人工审核。
2. “文件与来源”接入 Excel/CSV/TSV 和结构化服务中的文件快照；“研报资料”接入文档知识库。上传的原件按 SHA256 保存，可下载核对；表格观测保留工作表、数值/日期/表头单元格、原值、公式状态、口径、转换和版本。首次新格式确认后，后续同格式可自动导入。
3. 普通默认对话按问题自动调用商品研究、结构化表格或知识库，无需选择专用智能体或勾选结构化分析。明确选择的知识库/文件范围仍受尊重；无明确选择时使用当前授权目录。模型不能指定账号、空间或服务 URL；服务用已核验 caller 和私有签名约束访问。

自动刷新不生成收费模型简报，不改个人判断、策略或已审核简报。个人研究仍按账号隔离，原件和研究事实按空间共享。

## 使用边界

- 自动接口只覆盖已接入的六类公开来源。SMM/钢联等继续使用已有终端文件通道；指标已登记不意味着已有自动接口。新供应商编码、单位/口径变化或跨来源冲突仍需要确认含义。
- 图片/扫描件 OCR 依赖知识库视觉模型；本次实测 TXT，PDF/Word/图片继续复用既有 WeKnora 解析管线，未宣称逐格式端到端全部验收。不会直接把 OCR 数字自动变成研究指标。
- XLSX/XLSM 保留公式文本和缓存值；二进制 XLS 保留原件和读取值但不提供公式文本。无缓存公式、错误/缺失数值不会补零。历史无原件记录不补造来源。
- 跨服务结构化导出按版本分页并冻结全量，最多 200 万行；复杂 SQL 沿用最多 50,000 行、16 字段的完整输入和执行时限，超限明确拒绝。普通序列聚合使用完整数据。
- 判断读取仍返回本人最新生效版/草稿，并明确版本；不是历史判断回放。保持现有显式专用智能体行为，不把所有 MCP、技能或沙箱带入普通默认对话。
- 默认单 Web worker，空间内使用 SQLite；WAL 与进程/文件锁已有并发验证，更大并发部署需另行评估。
