# 中哲物产研究工作台

将知识库、结构化表格和商品研究整合在同一工作台，帮助研究人员从资料中查找依据、从数据中计算结果，并持续保存研究判断。

项目基于 [WeKnora](https://github.com/Tencent/WeKnora) 扩展，使用统一的登录、空间和对话入口。

## 核心能力

| 能力 | 说明 |
|---|---|
| 资料管理 | 集中管理文档、报告和表格，在对话中检索资料，并通过引用回到原文。 |
| 表格录入 | 识别工作表和独立数据区块，核对字段、单位、时间与范围后导入；支持调整映射和重新导入。 |
| 数据分析 | 按实际字段查询、筛选、统计和比较数据，由程序执行计算，保留缺失值及其原因。 |
| 来源追溯 | 保留原文件、工作表、表头、数值与时间单元格、公式缓存，以及历史导入版本。 |
| 商品研究 | 汇集指标、研究判断、简报和策略，支持数据定时刷新、手动更新和处理状态查看。 |
| 统一问答 | 根据问题结合知识库、表格和研究结果回答，无需为不同数据类型切换智能体。 |

## 数据与回答原则

- **先理解，再取数。** 模型根据问题、对话上下文与真实来源制定查询或分析计划，程序验证权限、参数、单位、范围和计算结果。
- **口径不清时澄清。** 同名字段保留各自的表头、维度和来源，不随意选择、合并或补写业务含义。
- **回答有据可查。** 文档引用和数值来源与实际读取的资料对应；缺失数据不当作零，缓存公式不冒充重新计算结果。
- **导入可核对、可追溯。** 页面区分“待核对”和“已可查询”，修改映射后重新检查；失败时保留已有可用数据。
- **按空间和账号隔离。** 共享资料与研究事实遵循空间权限，个人判断和研究思路按账号保存。

## 项目组成

| 目录 | 职责 |

| [`structured-data/`](structured-data/) | 表格扫描、字段映射、结构化查询与计算、图表来源和版本管理。 |
| [`commodity-research/`](commodity-research/) | 商品指标采集、刷新任务、研究判断、简报与策略。 |
| [`docs/`](docs/) | 功能设计、数据规则、问题审计与验证记录。 |
| [`deploy/`](deploy/) | 发布、服务器运维和上游同步工具。 |
