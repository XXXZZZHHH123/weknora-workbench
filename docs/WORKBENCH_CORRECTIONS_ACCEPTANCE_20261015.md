# 研究工作台修正验收记录（2026-10-15）

本次已验证：从独立空账号、空知识库和空工作台开始，保存桌面目录的 14 份原件，人工核对其中一个真实工作表、一个指标，导入 2,838 条观测，再用刚确认的指标建立原研究界面的新产业图。所有导入观测的日期和数值逐条与原件一致；另一知识库的空台保持零资料、零指标、零观测。

覆盖范围需要区分：**14 份文件完成原件保存、相对路径保留和下载 SHA256 核验；只有一个工作表、一个指标完成深度解析与研究导入验收。**其他文档未进行语义解析，不能据此声称整个目录已完成研究建模、所有工作表已核对，或已自动重建完整研究判断、策略和简报。

## 真实原件冷启动

验收服务为 `http://127.0.0.1:19480` 的独立栈。使用本次新生成的随机账号及空间，与页面交互测试账号分开；新建两个不同知识库及各自的独立工作台。没有读取或复制现有 18080 业务库、旧研究台或旧验收数据库。

1. 在新账号下核验初始知识库和工作台列表为空，两台初始资料、指标、观测均为零。空产业图取值请求返回 `200`、`as_of: null`，确认实际服务已加载本次修复。
2. 只读 Windows 桌面目录的 14 份真实原件，以 `source_only` 保存到第一个知识库。逐份从原生下载接口取回，14 份 SHA256 全部一致，14 条相对路径全部保留。`source_only` 表示保存原件，未把这一阶段记为文档解析成功。
3. 对真实 Excel 原件重新扫描，确认 `use_reviewed_mappings` 为 `false`。直接读取原始工作表的元数据、日期列和同行数值，确认所选内容为实际观测，而非取数要求或规范；人工明确选择一个字段及原单位、频率和表头证据。
4. 通过当前工作台的来源用途、工作表预览及确认、指标预览及确认接口导入。登记采用原表日期；登记时刻仅用于保留日期标签，不代表实际发布时间或当时可知性。
5. 导入 1 个指标、2,838 条观测。完整分页读取这些观测，逐条核对日期、数值、原件 SHA256 及值单元格、日期单元格定位，全部与原件一致。
6. 只使用本次指标确认响应返回的真实 `series_id`，通过原产业图接口新建最小研究图。GET 和 POST 取值的数值、日期均与原件一致；原指标详情页面及历史接口可用。
7. 对另一个知识库的空台请求同一指标绑定，返回指标不存在及空值；该台资料、指标、观测仍全部为零。空台没有继承第一个工作台的指标或研究图。

验收空间的外部供应商模型登记数为零。本流程未调用外部模型，也未操作云端服务。
