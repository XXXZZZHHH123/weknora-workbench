# 问答来源准备与复核策略

智能体配置 `answer_review_mode` 控制回答复核，和模型的思考强度独立。编辑智能体时，可在回答复核策略中选择：

- `standard`（实用）：普通文字问答完成后，保留真实引用身份、版本及现有结构化数值校验，跳过独立语义审核和候选答案补充。模型自行判断证据是否足够并说明必要的不确定性。普通文档内容不再经过独立模型逐项事实复核，可能遗漏或误读。
- `strict`（严格）：保留独立完整性与来源审核。每份候选答案的审核读取和无效协议重试共享最多 60 秒、12,288 个输出 token 的预算；超时不会变成审核通过。
- 空值（使用默认策略）：工作台默认入口采用实用策略；其他旧入口保留原策略。编辑旧配置时不把空值自动改成显式配置。

实用策略不依据任务规划自动提高模型思考强度；用户已有的思考开关和强度仍然有效。文件、图表和工作区操作必须有实际执行或交付证据，不能用回答文字替代成功结果。工具权限和来源身份校验不受复核策略影响。

实用策略的普通来源问答在 8 轮实际工具调用，或本轮活跃执行达到 60 秒后，于已完成的工具边界组织初步答案。每次主模型调用及重试前还会核对这一阶段的剩余时间，符合范围的单次模型生成最多 25 秒；超时的半个工具参数不能执行，也不会按瞬时错误继续重试。默认决策输出预算最多 4,096 token，显式配置的大预算保留。最终组织答案与必要修复另有共享 35 秒预算，普通叙述只交付有来源支持的核心结论，精确格式仍遵守用户要求。

回答仍需通过现有引用与数值校验，并说明尚未覆盖的部分；预算本身不代表任务完成。这个规则只适用于模型计划为文字、计划与实际工具均确认是只读来源能力的任务。未知能力、文件和操作、子任务、审批及人工等待保持原流程，更小的原迭代预算仍优先。正在执行的读取不被中断；来源准备、协作和保护边界也必须完整结束，因此 60 秒取证加 35 秒收尾是阶段预算，不是整个 HTTP 请求必定在 95 秒内成功的承诺。严格策略不采用上述普通问答预算。

实用策略同时约束规划和回答：当前日期辅助理解用户实际表达的相对时间，不把一般概况自动扩成特定年份的实况；及时回答可支持的核心结果，避免额外逐项分析及无依据的完整性、极值或正负区间结论。普通文字问答不做独立语义审核，模型解释仍可能出错。

用户未明确要求图表、文件等交付时，实用策略优先规划文字回答。模型以 `delivery_requirements[].format` 区分普通叙述（`prose`）与 JSON、代码等精确格式（`exact`）。预算收尾会发出初步结果状态；普通叙述同时在正文标明初步结果，精确格式及未声明格式的旧计划保持正文格式，不插入额外文字。

来源渠道由模型根据完整问题、上下文及可用能力选择。规划协议的 `source_discovery.source_domains` 包含 `knowledge`、`structured`、`external`，只准备所需的内部目录。稳定通用知识及整理已提供材料可选择 `none`。规划失败时保留实际工具供执行模型选择，不自动预取所有内部目录；执行中可通过 `expand_task_tools` 扩展实际允许的能力。

首次明确的 `read_document` 目标可在同一次调用中经真实元数据与权限校验建立来源绑定，无需重复提交来源声明。既有来源计划、用户选中文档和已核验页码限制仍生效；比较或更换来源应显式声明完整来源计划。资源句柄只用于原图参数，不能替代所属文档句柄。失败调用保持失败状态，时间线可展开查看具体原因，不把读取失败显示为没有匹配内容。

工具参数按当前实际能力提供：不支持地区或时间筛选的搜索引擎不会向模型暴露对应参数，显式筛选也不会被静默忽略；无效子任务名会指出字段与真实格式，未知工具名会返回可发现的授权目录。SQL 的语法解析和执行绑定错误均返回可纠正的结构化失败，声明查询未完成并保留 DuckDB 输入表契约；程序不改写查询或生成成功结果。模型仍可能提交错误参数，修正后才会真正执行。

工作台的新模型请求使用紧凑来源计算协议。真实 Markdown 表格沿用 `analyze_document_tables` 或 `calculate_document_table` 的行列批量计划；非表格正文和展平文字先用 `calculate_source_values` 的 `inspect` 取得数字引用，再提交 `calculate` 的共享引用、公式及原单位。程序从实际读取中提取原值与连续原文，复用来源、单位和有理数四则校验，不让模型重复抄值和长引用。引用仅在当前执行中有效，分页未返回的编号、历史或更新版本不能借用。目录和引用编号不是计算结果；展平图表标签也不自动成为曲线观测。模型继续负责完整问题的理解、来源选择、业务口径及公式，程序不猜测或修正公式。旧调用的文字引用参数继续兼容。

网络搜索仍需要空间配置可用搜索引擎、智能体允许联网及当前请求开启联网。知识库没有相关内容，不代表一般知识问题不可回答；外部事实也无需先检索内部来源。没有搜索结果时不得编造实时观测值。

`read_document` 的显式 `image_mode=geometry` 可直接读取受支持的原件矢量几何，不依赖 PNG 转换。返回结果单独标明几何状态，不能声称已看过像素。权限、原件哈希、资源字节、物理页和部件绑定仍须验证；不支持的原图会报告失败。

完成事件的执行耗时包含本轮规划与来源准备。恢复执行重新计算活跃区间，不把等待人工输入的时间计入模型执行。
