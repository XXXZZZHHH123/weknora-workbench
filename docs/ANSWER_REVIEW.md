# 问答来源准备与复核策略

智能体配置 `answer_review_mode` 控制回答复核，和模型的思考强度独立。编辑智能体时，可在回答复核策略中选择：

- `standard`（实用）：普通文字问答完成后，保留真实引用身份、版本及现有结构化数值校验，跳过独立语义审核和候选答案补充。模型自行判断证据是否足够并说明必要的不确定性。普通文档内容不再经过独立模型逐项事实复核，可能遗漏或误读。
- `strict`（严格）：保留独立完整性与来源审核。每份候选答案的审核读取和无效协议重试共享最多 60 秒、12,288 个输出 token 的预算；超时不会变成审核通过。
- 空值（使用默认策略）：工作台默认入口采用实用策略；其他旧入口保留原策略。编辑旧配置时不把空值自动改成显式配置。

实用策略不依据任务规划自动提高模型思考强度；用户已有的思考开关和强度仍然有效。文件、图表和工作区操作必须有实际执行或交付证据，不能用回答文字替代成功结果。工具权限和来源身份校验不受复核策略影响。

两种策略均先按既有额度修复未匹配数字（最多两次）。修复用尽后，优先交付本轮仍有效、数字已通过校验的候选并提示；没有时，可交付最近一份仅因数字未匹配而失败的候选，在每个未匹配数字的实际位置追加 `〔未核验〕`，文末提示以引用的原始资料或取数结果为准。该交付不代表数字核验通过；引用身份、权限、版本、范围、当前任务与证据修订，以及图片的真实成功执行来源仍须有效。图片、链接、引用标签、代码块和表格结构不得被标注破坏；不满足这些条件时保留原失败提示。

引用身份检查也沿用原修复额度。修复用尽或运行已无法继续修复时，若最后一稿只剩当前真实已读来源的引用视图无法核对，可删除失败引用标签，在其实际位置替换为 `〔引用未核验〕` 后交付；其余有效引用保留，失败引用不进入 references/evidence 列表。这不代表引用支持相邻主张或答案已通过语义审核。未知或伪造 ID、跨文档/库身份、权限或当前绑定范围越界、明确版本冲突与失效证据仍失败关闭，不能用标注绕过。标注只修改独立的正文或表格引用节点，不能改写代码、链接、图片或 HTML 属性中的示例。若同稿也有数字未匹配，同时按数字规则逐处标注，文末合并为一条提示；终止日志记录 `citation_unverified` 或 `citation_numeric_unverified` 及两类标注数量。一般语义审核失败不自动归入此引用身份交付规则。

检索与读取的真实分块身份来自同一批量加载的记录。摘录携带原正文哈希、版本和字符范围的投影描述；缺字段的旧视图只能借助身份完整且内容可逐字核对的当前见证归并，不能补造缺失字段或扩大已读范围。引用修复反馈逐标签提供失败类别及真实可用分块导航；片段是否覆盖所述时期、指标或范围由审核模型根据实际正文判断，程序不替模型选择业务口径。

本轮成功且身份、版本、当前文档/页范围有效的读取正文，可独立证明答案中转述的相同原数字，不以是否插入引用标签为前提；只有实际返回的正文进入证据池，未返回的全文、历史轮、失败读取、目录与计算 inspect 引用不能提供原值依据。派生数字仍须真实计算结果，失败或过期的计算引用不会使独立有效的正文读取整体作废。

绘图语义核验分别返回图本身的问题与其他待交付内容。图的变量、维度、单位、范围、图型及来源映射通过后，即使还需文字分析、其他图或文件，也可交付该图片；工具结果会提示执行模型继续完成剩余内容。图片放行不代表整轮任务完成，独立轴类型判定、来源绑定及最终回答核验保持有效。

结构化读取和绘图的 `inspect`、`map`、`render` 在所有入口纳入本轮实际进展检查。相同来源目录、相同来源与映射、相同真实查询结果不因调用 ID、SQL 写法或展示提示变化而成为新证据；实际保存一张新图才计为绘图交付进展，核验退回、映射错误及越界失败计入停滞。连续 3 个工具轮次没有新证据时要求重规划，6 个轮次时停止工具；普通文档停滞沿用工作台范围。另有每轮累计 4 次 `render` 未交付上限，保存成功不清除已累计失败；上限工具结果保留真实失败原因并要求执行模型立即完成文字回答。

停滞后仅在已有本轮真实执行结果时进入无工具最终合成，纯目录及失败记录不触发额外合成；绘图上限和最大轮次也复用同一收尾路径。既有父子协作的失败归属仍优先，未完成子任务不提供结果证据。收尾使用真实结果整理正文，说明未完成范围和绘图失败原因；停滞与绘图上限沿用 main 的 35 秒预算，最大轮次收尾最多 60 秒，包括压缩、生成、修复与复核，已有更小阶段预算仍优先。模型流等待响应上下文截止，不能因为供应商没有关闭流而无限等候。最终候选继续经过数字、引用与来源检查，并沿用前述修复用尽后的标注交付；达到执行边界不等于核验通过。若模型不可用、收尾超时或候选仍无法安全交付，提交明确的非空失败说明，不发布未校验草稿。用户主动取消不再合成，失效或被替代的执行租约仍保持原保护。

同轴已知混合单位在渲染与语义核验前直接拒绝；`mixed` 与 `unknown` 分开表达，未知单位仅允许无单位声称的原值展示。语义核验保留全部未选来源列与对应行，检查真实业务度量与维度是否被汇总图例掩盖；不同度量混轴、必要维度未区分必须进入 `chart_issues`，其余文字未交付只进入 `pending_deliverables`。标签与单位可由受限真实列投影取得，不能通过模型手写标签或改写技术 ID 绕过保护。

实用策略的普通来源问答在 8 轮实际工具调用，或本轮活跃执行达到 60 秒后，于已完成的工具边界组织初步答案。每次主模型调用及重试前还会核对这一阶段的剩余时间，符合范围的单次模型生成最多 25 秒；超时的半个工具参数不能执行，也不会按瞬时错误继续重试。默认决策输出预算最多 4,096 token，显式配置的大预算保留。最终组织答案与必要修复另有共享 35 秒预算，普通叙述只交付有来源支持的核心结论，精确格式仍遵守用户要求。

回答仍需通过现有引用与数值校验，并说明尚未覆盖的部分；预算本身不代表任务完成。这个规则只适用于模型计划为文字、计划与实际工具均确认是只读来源能力的任务。未知能力、文件和操作、子任务、审批及人工等待保持原流程，更小的原迭代预算仍优先。正在执行的读取不被中断；来源准备、协作和保护边界也必须完整结束，因此 60 秒取证加 35 秒收尾是阶段预算，不是整个 HTTP 请求必定在 95 秒内成功的承诺。严格策略不采用上述普通问答预算。

实用策略同时约束规划和回答：当前日期辅助理解用户实际表达的相对时间，不把一般概况自动扩成特定年份的实况；及时回答可支持的核心结果，避免额外逐项分析及无依据的完整性、极值或正负区间结论。普通文字问答不做独立语义审核，模型解释仍可能出错。

用户未明确要求图表、文件等交付时，实用策略优先规划文字回答。模型以 `delivery_requirements[].format` 区分普通叙述（`prose`）与 JSON、代码等精确格式（`exact`）。预算收尾会发出初步结果状态；普通叙述同时在正文标明初步结果，精确格式及未声明格式的旧计划保持正文格式，不插入额外文字。

来源渠道由模型根据完整问题、上下文及可用能力选择。规划协议的 `source_discovery.source_domains` 包含 `knowledge`、`structured`、`external`，只准备所需的内部目录。稳定通用知识及整理已提供材料可选择 `none`。规划失败时保留实际工具供执行模型选择，不自动预取所有内部目录；执行中可通过 `expand_task_tools` 扩展实际允许的能力。

首次明确的 `read_document` 目标可在同一次调用中经真实元数据与权限校验建立来源绑定，无需重复提交来源声明。既有来源计划、用户选中文档和已核验页码限制仍生效；比较或更换来源应显式声明完整来源计划。资源句柄只用于原图参数，不能替代所属文档句柄。失败调用保持失败状态，时间线可展开查看具体原因，不把读取失败显示为没有匹配内容。

工具参数按当前实际能力提供：不支持地区或时间筛选的搜索引擎不会向模型暴露对应参数，显式筛选也不会被静默忽略；无效子任务名会指出字段与真实格式，未知工具名会返回可发现的授权目录。SQL 的语法解析和执行绑定错误均返回可纠正的结构化失败，声明查询未完成并保留 DuckDB 输入表契约；程序不改写查询或生成成功结果。模型仍可能提交错误参数，修正后才会真正执行。

工作台的新模型请求使用紧凑来源计算协议。真实 Markdown 表格沿用 `analyze_document_tables` 或 `calculate_document_table` 的行列批量计划；非表格正文和展平文字先用 `calculate_source_values` 的 `inspect` 取得数字引用，再提交 `calculate` 的共享引用、公式及原单位。程序从实际读取中提取原值与连续原文，复用来源、单位和有理数四则校验，不让模型重复抄值和长引用。引用仅在当前执行中有效，分页未返回的编号、历史或更新版本不能借用。目录和引用编号不是计算结果；展平图表标签也不自动成为曲线观测。模型继续负责完整问题的理解、来源选择、业务口径及公式，程序不猜测或修正公式。旧调用的文字引用参数继续兼容。

网络搜索仍需要空间配置可用搜索引擎、智能体允许联网及当前请求开启联网。知识库没有相关内容，不代表一般知识问题不可回答；外部事实也无需先检索内部来源。没有搜索结果时不得编造实时观测值。

`read_document` 的显式 `image_mode=geometry` 可直接读取受支持的原件矢量几何，不依赖 PNG 转换。返回结果单独标明几何状态，不能声称已看过像素。权限、原件哈希、资源字节、物理页和部件绑定仍须验证；不支持的原图会报告失败。

完成事件的执行耗时包含本轮规划与来源准备。恢复执行重新计算活跃区间，不把等待人工输入的时间计入模型执行。

## 2026-11-16 文档零命中与覆盖恢复

`read_document.query` 是同一分块内所有词的字面过滤，不是主题检索；主题或改写措辞的查找应优先用 `search_knowledge.document_ids`，或依据真实页码/位置读取。只有非正则查询从 offset=0 完整扫描全文且字面零命中时，才用原 query 在同一文档做最多五块语义召回。召回复用正常搜索的授权、当前来源计划及批量原始分块身份，按正常读取输出正文及字符续读位置。`query_scope.fallback=semantic_within_document` 区分召回与字面命中；零命中、召回和分页状态均不证明主题或整文覆盖。服务、语义索引或真实分块见证不可用时明确返回召回不可用，不伪造正文，不扩写查询。

实用策略的八轮计数以每批是否有实际取证操作为准：整批均被本地参数、权限或来源计划前置校验拒绝时不计取证轮数；成功、实际执行后的业务失败，以及无法明确分类的旧结果仍保守计入。分类来自程序设置的前置拒绝状态，不解析错误文字。被拒绝的工具边界仍计入活跃时间、停滞与原迭代上限，不能无限重试，也不重置六十秒。

实用预算收尾中，若覆盖审核明确返回 `need_source/discovery_coverage_recovery`，原迭代上限仍有空间且收尾实际剩余至少十五秒，可花费既有一次候选修复额度，进行一次仅开放 `read_document` 的模型轮。模型按完整任务与审核意见选择至多四次读取；程序整批核验文档必须来自本轮成功的原生搜索、目录、绑定或读取结果，禁止改变来源计划、读取图片或展开其他工具，执行时再次校验当前授权、绑定和用户页码范围。模型与读取共同最多十秒，全部计入原三十五秒收尾；失败、无调用或超时也不能再开第二批。之后继续无工具最终合成与原数字、引用核验，不返回普通工具循环，不重置迭代或修复额度。只有文档已发现才有读取机会，导航和审核意见本身不能成为证据。
