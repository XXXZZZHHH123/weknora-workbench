# 文档问答执行恢复与来源表格交付

本文记录执行协议、来源范围、重复调用保护和程序构表的实现边界。模型根据完整用户问题、上下文及真实来源作选择；程序验证权限、身份、范围、单位、数值和执行结果。不按问题关键词、商品、日期、文件名、列号或模型名称分流答案。

## 来源范围与读取计划

`bind_document_scope` 验证实际授权文档及文件名或标题。`page`、`pages` 是可重新规划的物理页读取提示，不自动成为用户限制。同一文档使用一个来源条目，多页放入 `pages`。

仅明确提供 `user_page_constraint` 时，程序接受模型解释的用户页码限制：页码列表必须合法，`user_quote` 必须精确出现在服务器提供的用户消息中。它是来源选择之外的约束，后续读取计划不能自行扩大或删除；真实用户追加指令需要重新结合完整上下文解释。程序不使用页码问题正则或关键词表推断业务意图。

精确引用只验证这段话来自用户，不能代替模型解释完整要求。扫描校验实际文档身份、数量和已观察到的来源版本；它不提供数据库事务级的整份文档快照，并发重解析仍需重新读取并核对来源。

`read_document.pages` 一次最多选择 8 个物理页，共用一次有序文档扫描。每页独立返回成功或错误、实际读取范围、完整性和继续读取游标。部分页面成功不代表整个批次或整个问题完成。`page` 是物理页，`chunk_page` 是文档分块列表的分页序号，`offset` 是明确命名的分块坐标；三者不能互换。分块正文的字符续读使用单独的 `content_offset`。

带查询的物理页读取只在所选页中匹配。零命中只描述此次扫描，不证明该页或整份文件没有所问信息。模型输出保留每页 `query_scope`、失败信息和继续读取游标，避免把缺失内容当作已读。

## 工具参数协议

`modelcontext.NormalizeToolArguments` 仅使用实际注册工具的 schema 处理可无损恢复的传输形式：

- schema 明确为对象或数组时，允许解开一层完整 JSON 字符串；嵌套字段按各自 schema 处理。
- 只有字段显式声明 `x-weknora-exact-decimal-string` 时，完整普通十进制数字 token 可以转为相同字面的字符串。其他数值、ID 或文本字段不据名称猜测类型。
- 重复键、截断内容、尾随文字、混合错误类型及缺少必要字段均拒绝，返回 JSON Pointer 字段路径和原因；不会补参数、猜 ID 或关闭截断括号后执行。

参数归一化后再解码来源句柄，避免编码字符串中的 `chunk_id` 留在自由文本的 URI 形式。原始提供方参数保留在 `ModelArguments` 中。句柄解析仍受真实工具字段所有权控制；外部 MCP、原生结构化工具的业务负载继续使用各自协议，不继承内建来源字段语义。

字符串句柄编解码使用 `json.Number` 保留无关数字的原始字面，避免经 `float64` 改写大整数或高精度小数。这是编解码边界及显式十进制字符串字段的精度保证，不等于所有外部工具内部的数值实现都具有相同保证。

## 执行进展与结束状态

执行器依据真实来源内容、元数据和已扫描范围记录进展。重复正文、查询措辞、调用 ID 或模型改写的读取提示不应冒充新证据。真正的新内容区间、页扫描或有效结果可以继续推进。

当前保护参数在 `tool_progress.go`：连续 3 个没有新增进展的工具轮次触发重新规划提示；连续 6 轮仍无进展进入有界结束。达到记录容量时停止该统计，避免把大型任务误判为停滞。其他真实工具工作不由纯文档证据统计判定失败。

`replanning` 是带实际运行说明的进度事件，保持独立事件 ID。它不进入最终答案正文，也不结束回复。前端已有的进度快照、重复事件去重和 `agent_steps.progress` 历史恢复路径处理此事件；最终结束仍等待持久化完成。

达到资源限制是运行状态，不是语义完成证明。正常结束、修复重试和资源耗尽仍经过共同的候选答案入口；来源、数值、单位和完整问题覆盖要求不因结束方式而豁免。

## 来源表格视图

`calculate_document_table` 的计算路径已经可以按真实表格行列批量读取原值并执行精确四则计算。`analyze_document_tables` 根据服务器保存的完整问题及实际已读表目录规划，再调用相同执行器；计划、建议和执行成功均不能替代完整覆盖判断。

新增的 `select` 路径选择真实来源行列，由程序构造 Markdown。成功选择或可展示的计算结果提供不可变视图快照及 `view_ref`，引用形式为 `document-table-view:sha256:<摘要>`。该引用属于当前执行的展示结果，不是文档句柄、引用资格或权限凭据。

模型选择交付该实际视图时，在最终草稿单独一行输出：

```xml
<document_table_view ref="document-table-view:sha256:<从成功结果复制的摘要>" />
```

示例中的占位文字不能作为真实引用使用。模型无需重抄数值、表头或整张表。模型上下文投影提供实际引用、来源句柄、所选行列、解析警告和执行覆盖信息；原始视图、指纹与单元格字符串保留在工具结果中。

最终交付边界验证本轮私有封存快照、真实成功执行、内容摘要及当前来源后，才把独立指令展开为程序生成的表格。未知、过期、篡改或不属于当前来源的引用不能展开。引号、代码和来源正文中的示例不是可执行指令。展开结果继续进入相同的来源、数值和语义检查；程序构表不提供审核豁免，也不能把部分结果包装成完整答案。

视图和目录中的行列坐标、计数、指纹及原文 JSON 不额外授予业务数值权限。原单元格仍依赖实际成功读取及对应引用；计算结果继续使用现有显式数值和单位校验。最终聊天渲染对原文标点采用字面编码，避免公式或强调预处理改写单元格，也不让数字 HTML 实体或技术列号产生额外业务数字。

分析批次部分失败时，可以显示实际成功子执行的视图，同时保留整个批次失败状态、失败行和覆盖缺口。成功子结果不提升整个批次的完成状态。

## 执行准备与索引并发

父任务取得执行所有权后，准备模型上下文、规划任务和发现来源也属于实际执行。会话使用有清理边界的执行域，在原有权限检查及取得所有权的位置立即启动续租；直接调用引擎时，`Execute` 和 `Resume` 也在准备前启动续租。同一执行域与所有者复用心跳，工厂失败、准备失败、取消和正常退出均释放资源。过期、被替换或关闭的所有者不能通过重新启动心跳恢复权限；准备结束后仍核对当前所有权。没有安全检查点的真正失联执行继续终止，不能自动重放不确定的工具操作。

跨知识库目录发现保留已成功读取的条目，并区分读取失败与尚未查询的范围。取消、超时或部分失败不能退回成目录读取成功，也不能证明未读范围没有数据。实际字段字面匹配继续只提供候选证据，由模型依据完整问题和真实来源选择范围。

原生图表索引按实际工作区、数据集及索引版本的缓存路径协调构建。持久文件锁覆盖线程与进程，取得锁后再次检查缓存，完成后原子发布；等待超限明确返回索引尚未就绪，不能另起同一构建或返回空证据。失败不发布半份索引，损坏或身份不符的缓存拒绝使用。HTTP 读取超时可能留下仍在运行的服务计算，因此只对明确未连通服务的纯读连接失败自动重试，不自动重放响应超时或状态操作。

这些改动保留来源、重复字段、日期、质量、单位和数值检查。单份大型冷索引首次构建仍可能超过 HTTP 预算；并发去重和准确状态不代表目录冷启动性能已经验收通过。
