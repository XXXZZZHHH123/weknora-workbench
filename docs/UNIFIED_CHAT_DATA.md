# 三个对话入口统一取数

## 用户行为

快速问答、智能推理及工作台管理的“表格数据分析（结构化）”使用同一组当前空间数据能力。用户无需切换智能体才能查表格。保留原有模型及推理设置；自建、共享或跨空间智能体不自动扩大权限。

每轮在第一次模型调用前，实际读取当前空间表格目录、只读操作参数，并检索用户问题对应的已授权知识库正文。显式选择的知识库、文档和标签继续限制正文检索。表格原值与程序计算提供数值依据，文档提供定义、单位和背景；两者冲突需要说明。

旧的工作台托管表格 MCP 连接由带当前调用者签名的原生接口替代，避免用固定试点空间身份。其他 MCP、技能和已配置沙箱保留。匹配使用托管标记及创建者/空间核验，不根据名称扩大范围。

## 原件和计算

`inspect_source` 按当前空间版本读取保留的 `source.xlsx`，读取前后核验 SHA256，可搜索未解析区域、读取指定范围及按单元格或有限 A1 范围求和。返回文件、版本、工作表、坐标、原值、公式及已保存缓存状态；不重新计算原 Excel 公式，不把缺失值当零。

问题含显式年度标签且字段目录定位到真实工作表时，自动对该表补一次原件标签搜索，避免整本工作簿早期截断漏掉年度小表；这一步不推定年度起止或选择区块。每轮提问按版本及工作表去重并限制补检数量。

搜索、输出和执行时间有上限，未完成扫描明确标记，并列出未扫描/未完成工作表及重试建议；参数过大或文件损坏返回失败，不冒充无数据。合法同表 Excel 引用、绝对坐标和小写坐标会归一化；跨表、外部文件和公式引用拒绝。

首次读取的真实参数定义注册成五个具名只读工具，避免模型猜测参数。原始结果完整保存，模型视图减少每格重复元数据，同时保留所有返回区块、公式状态和计算证据。提交表格答案前独立复核口径，并检查统计数字是否有程序依据。混合回答中，文档数字仅从本轮真实成功读取、且最终回答实际引用的正文片段取得；未引用片段及正文嵌入的伪工具结果不作为数字依据。来源哈希的完整值、唯一可匹配的前后缀缩写以及原件行号按来源标识处理，避免误当统计。

## 棉花验收口径

问题：`2022/23年度中国棉花产量加进口，合计是多少？`

独立读取当前本机 `棉花数据库(2).xlsx`、`中国棉花平衡表`，版本 `424aed70d6a68ef7b97a067e`，原件 SHA256 为 `108b08e3f40b1f2cb081ca406fdc4bd02415dce5ffd2c7426d078c79573bd1fe`。

| 原表位置 | 年度标签 | 产量 | 进口 | 原值合计 |
| --- | --- | --- | --- | --- |
| AF83 / AG83 / AH83 | 22/23 | 650 | 125 | 775 |
| AF90 / AG90 / AH90 | 22/23 | 650 | 127 | 777 |
| BX31 / BY31 / BZ31 | 22/23 | 650 | 125 | 775 |

这些区块位于旧解析范围 A2:Y170 之外，不能直接选其中一组为唯一答案。原件未提供可靠区块优先顺序，相关字段单位和年度起止也没有得到可信定义。因此首问应说明 775 / 777 的差异及来源，请用户选择口径。

同一会话随后明确指定 `2022-09-01 至 2023-08-31` 的月度产量、进口原值：C74:C85 合计 650，D74:D85 合计 127.008062964705883，总和 777.008062964705883，显示可四舍五入为 777.0081。此条件是用户指定的月度范围，不证明年度表定义或单位；不能自行补为“万吨”。

验收使用同一账号、空间和模型，三个全新会话分别运行原问题及上述追问；检查实际知识库/表格调用、原件哈希、三个年度区块、程序合计、日期范围和单元格来源。期望值来自独立原件读取，未向知识库植入测试答案。

## 本机最终验证（2026-10-12）

最终构建下三个新会话均实际查询知识库及结构化目录，首问均读取三处年度区块并澄清 775 / 777。原题的知识库检索未找到可靠年度/单位定义，因此没有用无关周报给原表补定义。
