# CDS 界面与交互升级

## 目标与边界

沿用现有 Vue / TDesign 架构，将 Open Claude UI 的设计与交互原则迁移到工作台。保留现有品牌、路由、权限、接口、数据处理、问答与工具执行行为。新增样式不接入参考项目的模拟模型、模拟工具或示例 Agent 数据。

## 实施计划

1. 建立统一设计令牌：暖中性色四层表面、陶土强调色、可读的明暗文字、细边框、分级圆角、浮层阴影、键盘焦点与减少动态效果支持；映射现有 TDesign 和应用语义变量。
2. 改善导航与对话：导航密度和选中层次、长标题、输入框焦点与按钮反馈、消息阅读节奏、来源胶囊、流式等待与窄屏排版。保持输入法保护、发送/停止、附件、来源选择和工具调用行为。
3. 统一周边页面：资源列表、空状态、设置弹窗、结构化工作区与研究工作区外壳。表格和代码保留自身滚动，状态色保留各自语义。
4. 验收并迭代：前端类型检查、既有相关测试、生产构建，以及真实后端上的桌面/窄屏、明暗主题、键盘、长内容和弹窗检查。独立审查功能边界和视觉细节后再推送。

## 并行开发

本次在独立 Git worktree / 分支实现。避免覆盖其它 agent 在问答、图片来源和结构化导入上的未提交工作。提交仅包含本次界面文件；最终合并前重新核对远端和共享工作区变化，冲突按具体代码处理，不重置他人改动。

## 设计取舍

- 通过语义令牌与 Vue 原生样式迁移，保持框架和现有组件行为。
- 强调色只用于主要操作、选中指示和焦点；正文以暖中性色保证阅读。
- 交互动效采用短时反馈，避免给表格和流式正文添加持续重排动画。
- 暗色主题、字体偏好、危险/成功/警告状态和禁用状态分别保留。
- 参考仓库的“生产级”“官方逆向”描述不作为本项目通过验证的依据。

## 字体与内嵌页面约定

- 导航、界面标题、表单、表格及引用胶囊使用 `--cds-font-interface`，继续跟随用户选择的 `--app-font-family`；助手长回答使用 `--cds-font-reading` 的系统衬线回退栈。代码使用 `--cds-font-code`，跟随用户等宽字体设置。不要把品牌四字子集当作正文中文字体。
- 研究与结构化数据页在同源内嵌时，只同步宿主的界面/代码字体变量并监听后续变化；独立或跨源运行保留本地回退，不复制缩放比例，不扩展认证或数据消息协议。数字仍保留 `tabular-nums`，不因此强制整个数据界面使用等宽字体。
- 知识库保留专属目录、权限和操作，仅统一字体、间距、图标与中性选中样式。关闭的研究抽屉仍保留平移动画，但取消关闭态投影，防止多个屏外抽屉在页面右边叠加黑影；打开态投影保留。
