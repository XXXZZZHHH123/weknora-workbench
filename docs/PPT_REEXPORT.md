# 旧 PPT 按原版式重新导出、同期异动清单与问答读取

状态：二期设计，开发中。依赖 [图表库与周期对比](CHART_LIBRARY.md) 一期。是否已部署以目标环境实际验证为准。

当前版本暂不提供 PPT 版式导出，`ppt_enabled` 默认关闭，专属页面与 API 均返回 404。可启用的完整版本保留在 `feature/ppt-templates` 分支；以下内容为保留实现的说明，不代表本版本已开放。

## 一、旧 PPT 重新导出

每位研究员的周报版式不同。研究员从当前研究台已授权来源知识库中选择以往的一期 PPT，平台直接复用知识库原件，识别其中的图位，绑定到图表库中的图表或指标；之后每期用最新数据、按原版式导出新的 PPT。仍可上传本地 PPT 作为备选。版式由研究员自己的文件决定，平台不提供统一模板。

### 解析（研究服务）

- 新建模板先打开选择对话框。`GET /api/sn/ppt-templates/sources?search=&offset=&limit=` 列出当前研究台已授权来源中的 PPTX，支持文件名搜索与分页；展示文件名、上传时间、大小，知识库提供页数时一并展示。读取复用当前研究台已核验的来源范围及当前用户的主平台 Bearer 身份和租户，不使用独立凭据，也不列出其他知识库；受限视角不开放此入口。清单与原件读取仍遵循主平台原有权限，不能用预览接口绕过原件下载限制。
- 选定后 `POST /api/sn/ppt-templates/from-source` 提交 `knowledge_base_id`、`knowledge_id`、`file_hash`。服务端重新核验来源范围、当前文件和哈希，通过主平台现有原件接口读取并解析（`.pptx`，≤ 60 MB）。模板保存来源引用、文件 SHA256、解析结果与绑定；不在研究台私有目录再保存一份知识库 PPT 原件。
- 备选上传仍为 `POST /api/sn/ppt-templates`（`.pptx`，≤ 60 MB），本地上传原件按 SHA256 保存在研究台私有目录，不进入知识库。此前已上传的模板继续使用原保存方式。
- 模板归创建者本人（同研究判断的个人归属），记录为 `workbench_artifacts`（`module = "ppt_templates"`），修改递增 `revision`。
- 按演示文稿顺序读取每页；收集 `p:pic`（包括组合形状 `p:grpSp` 内的）中 `a:blip r:embed` 引用的图片，记录形状编号、关系编号、媒体部件、位置与尺寸（EMU）。PowerPoint 原生图表对象（`c:chart`）与 SVG 图片一期不处理，按普通图片保留。
- 每页标题取该页第一个非空文字段落。
- EMF 图片读取文字记录（`EMR_EXTTEXTOUTW` 与 EMF+ `DrawString`），每个图位最多保留 200 段文字。
- 图位类型只按结构判断：
  - `table`：文字中完整 ISO 日期 ≥ 3 个，且"日期后紧跟数值"的配对占主要部分，记录这些配对；
  - `chart`：EMF 中有 ≥ 3 个数值刻度样文字；
  - 其余为 `image`（PNG/JPEG、无文字 EMF）。

### 候选与确认

- 图位绑定只有两种：`chart`（图表库中的图表 id）或 `series`（数据小表：指标 id 与显示的行数）。
- 候选只用于召回，不直接决定绑定（`AGENTS.md`）：
  - 图位：用图位文字与图表库图表的标题、曲线名、段标签和单位做相似度，列出前 3 个候选；
  - 数据小表：在当前研究台目录中查找"小表中 ≥ 80% 的（日期, 数值）配对与观测一致"的指标；数值按小表显示的小数位四舍五入后比较。满足的候选标记为"数值已核实"，仍需研究员确认。
- 研究员逐页确认，可以"按候选确认本页"批量确认，也可以手动选择图表或指标，或标记为"保留原图"。
- 一期模板绑定的图表必须属于同一研究台图表库，读取时仍按图表库权限检查。

### 导出

- 知识库模板的列表和详情返回当前来源状态：原件可用、知识库原件已变化、知识库原件已删除，或当前授权/服务无法核验。原件变化或删除时禁止导出；暂时无法核验时也不使用历史原件或静默读取新文件。导出前按保存的 `knowledge_base_id`、`knowledge_id`、`file_hash` 重新读取原件，并核对实际文件 SHA256。
- 用户可在选择对话框重新选定知识库文件，`PATCH /api/sn/ppt-templates/{id}/source` 提交 `revision` 和新的来源引用。该操作是显式接受所选原件，会重新解析并清空旧图位绑定，避免将旧图位坐标或绑定直接套到变化后的文件；需要重新确认图位后再导出。已生成的导出结果仍可按原保留规则下载。
- 导出页 `/sn/reports/ppt/{id}/export` 选定数据截止日后，在浏览器中用图表组件按每个图位的宽高比渲染绑定图表（2 倍像素），数据小表渲染为表格图片（行数与原表一致，取截止日前最新观测）。
- 浏览器把 PNG 和生成图位时读取的模板 `revision` 提交到 `POST /api/sn/ppt-templates/{id}/export`（≤ 400 张，每张 ≤ 4 MB）。知识库模板必须携带版本号；与当前记录版本不一致时拒绝导出，要求重新加载并生成图片。重选原件与导出共用模板文件锁，并通过 `revision` 比较后更新记录，防止重选期间的旧 PNG 套入新解析的版式或旧请求覆盖新来源。服务端复制核验过的原件，为每个图位新增 PNG 媒体部件，改写该页关系指向新部件，必要时在 `[Content_Types].xml` 中登记 `png`。形状位置、尺寸、裁剪和其他内容不变。
- 没有绑定、绑定失效、数据读取失败的图位保留原图，列入导出报告并说明原因。
- 标题文字不改写。含数字的标题列入"需核对"清单；勾选"标黄提示"时为这些标题加黄色高亮。
- 返回新的 `.pptx` 与导出报告（已更新图位、保留原图图位及原因、每张图的数据截至日期、需核对标题）。
- 导出不写入知识库，不生成或发布研究结论。每个模板在研究台私有目录保留最近 5 份导出结果；这一规则与知识库原件不复制到研究台的规则相互独立。

### 页面

- `/sn/reports#report-ppt`：日报周报中的"按我的 PPT 版式导出"区域，默认折叠；展示个人模板名称、页数、"已绑定 / 保留原图 / 待确认"统计、原件状态、最近导出时间与下载链接，提供新建模板、绑定图位和导出入口。新建对话框默认选择已授权知识库 PPT，保留"上传本地文件"备选；支持搜索、分页、选择与错误提示。查看某一期日报或周报时，导出默认沿用该期日期；受限视角不显示此区域。顶部导航不再单设"PPT 模板"入口。
- `/sn/reports/ppt/{id}`：逐页显示版面示意（图位方框按原位置比例排布）、每个图位的识别文字、候选（带图表缩略图）与绑定状态；底部汇总"已绑定 / 保留原图 / 待确认"。
- `/sn/reports/ppt/{id}/export`：选择截止日、预览各图位新图、导出并下载、查看导出报告；支持 `?date=YYYY-MM-DD` 预填截止日。绑定页和导出页面包屑为"日报周报 › PPT 版式 › 模板名"，导航高亮"日报周报"。
- 旧地址 `/sn/ppt`、`/sn/ppt/{id}`、`/sn/ppt/{id}/export` 保留查询参数并跳转到上述对应入口；接口仍为 `/api/sn/ppt-templates`。

## 二、本周同期异动清单

- `GET /api/sn/charts/anomalies?date=&limit=`：对图表库中所有周期模式图表，在截止日计算周期位置，并在上一条观测日再算一次。
- 列入清单的条件：同期排名为前两高或前两低（往期有效段数 `n` ≥ 3）；或与上一条观测相比排名变化 ≥ 2 位。
- 每项返回图表、指标名、日期、当前值、`rank/(n+1)`、上一观测排名、`share_below`、较近 5 期均值，以及原因（`extreme_high` / `extreme_low` / `rank_change`）。排序：极端值在前，再按排名变化幅度。
- 读取按页面取数上限分批（每批 ≤ 256 个指标、合计 ≤ 20000 点）；单个图表失败时列入 `failed`，不影响其他图表。
- 展示在图表库顶部（可折叠的"本周同期异动"）和日报周报页的入口链接。只陈述位置与变化，不给方向判断。

## 三、问答读取图表库与周期对比

- 商品研究工具新增两个只读操作：
  - `charts`：按标题、分组或指标搜索图表库，返回图表 id、标题、模式和页面链接；
  - `cycle`：给定 `series_id`、可选 `template`（内置模板名或已保存模板 id）和 `date`，返回周期位置、往期区间、较近 5 期均值、往期后续汇总、省略周期与警告。不返回全部曲线点。
- 由模型根据完整问题选择指标、模板和日期，程序校验指标权限与参数后计算（`AGENTS.md`）。工具说明中注明"往期后续是历史参照，不是预测"。
- 研究服务 `/api/tools/read` 增加对应操作；WeKnora 工具 `commodity_research` 的参数枚举与字段同步扩展（需要重新编译后端）。
- 问答中画周期图、把问答图另存为图表放到三期。

## 四、验收

- 两个服务及 WeKnora 相关测试通过；新增测试覆盖 PPT 解析（组合形状、EMF 文字、表格配对、原生图表与 SVG 保留）、候选（数值核实规则）、导出（关系改写、内容类型、保留原图、标题高亮、原件不变）、权限（个人模板、受限视角）、异动规则、问答操作参数校验。
- 用本机棉花周报 PPT 实测：解析出的图位数量与离线统计一致（0331 期：EMF 279 个，其中数据小表 32 个）；绑定若干页后导出，PowerPoint 格式校验通过，版式不变，绑定图位换成新图，其余图位保留。
- 测试夹具使用合成 PPT，不提交真实业务文件。
- 知识库模板测试覆盖已授权来源范围与主平台权限、搜索与分页、按引用创建、原件哈希变化与删除状态、导出时重新读取和核对原件、知识库原件不另存，以及重新选择后重新解析和清空绑定。页面测试覆盖新建对话框、搜索、分页、选择、本地上传备选、异常原件状态和日报/周报区域。具体执行结果以本次任务的测试记录为准。
