# 报告 PPT 导出、同期异动清单与问答读取

状态：新版报告 PPT 导出已实现，依赖 [图表库与周期对比](CHART_LIBRARY.md) 一期。是否已部署以目标环境实际验证为准。

## 一、PPT 导出

日报、周报页通过“导出 → 导出为 PPT”直接下载本期报告，无需绑定版式或外部模板。对话框默认选择报告当前显示的导语、研判、图表和策略；可以取消部分内容，隐藏的节不能在导出时重新开放。每页图数可选 1、2、4，默认 2。关闭研判或策略的文字节不改变当前报告已组成的完整图表清单；关闭图表节才不导出图片。

- **内容来源**：服务端重新生成与报告页、Markdown 共用的报告视图，依次输出封面、选中的导语/研判/图表/策略、说明页。不接收客户端报告文字，不调用模型。沿用已保存结论、策略、研究员按语和明确版本的引用；保留当前规则试算、数据日期和过旧提示。条件触发不等于成交。
- **默认版式**：python-pptx 从空白演示文稿生成 13.333 × 7.5 英寸白底宽屏。内容页左上角为中哲集团 logo（高 0.5 英寸），主红色取自 logo 的主色像素 `#BE0008`；只用于标题细线、页码等点缀。中文指定 Microsoft YaHei，西文 Arial；标题 24–28pt、正文 14–16pt，脚注最低 11pt。页脚标注数据截止日、工作台名和页码。长文字、长条件表格自动续页，不缩小字号硬塞。
- **图表**：保留 P1 完整清单及顺序。浏览器通过既有逐图读取接口，按幻灯片图位宽高比，用 ChartKit 白底导出样式绘制 2 倍像素 PNG。失败图保留标题、图说和灰色占位框，失败原因使用服务端已核验提示或通用中文说明。历史冻结归档只列图表标题、引用处，注明“历史归档不重新绘图”，不重读图表。
- **接口**：`POST /api/sn/reports/{date}/{daily|weekly}/ppt`，multipart 字段为 `options`（JSON，`sections: {summary,research,dashboard,watch}` 布尔开关、`figures_per_slide: 1|2|4`）、`revision`（JSON 草稿版本或 null）、`keys`（JSON 有序图表 key 清单）、重复 `images`（成功图的 PNG，顺序为 keys 去掉失败项）、重复 `failures`（JSON `{key,reason}`，仅报告绘制失败，不将客户端 reason 写入正文）。未选图表节时 keys/images/failures 均为空；冻结归档提交完整 keys，images/failures 为空。
- **权限与版本**：受限视角 403；无研究台 409；具备报告读取权限的账号即可导出，不要求编辑权限，浏览器 POST 继续校验同源。服务端重建清单，keys 集合、顺序或草稿 revision 不一致返回 409“报告内容已变化，请刷新后重试”；保留来源权限、真实 ID、固定修订及不可读引用保护。
- **上传与返回**：每张 PNG 最大 4 MiB、宽高各不超过 4000px；校验文件头、格式及完整解码。超大返回 413，图片损坏、尺寸或数量不符返回 422。成功直接返回 PPTX，`Content-Disposition` 以 RFC 5987 UTF-8 文件名包含工作台、日报/周报和日期区间。不写入知识库、不保留生成文件；multipart 临时文件在请求结束时关闭清理。

## 二、本周同期异动清单

- `GET /api/sn/charts/anomalies?date=&limit=`：对图表库中所有周期模式图表，在截止日计算周期位置，并在上一条观测日再算一次。
- 列入清单的条件：同期排名为前两高或前两低（往期有效段数 `n` ≥ 3）；或与上一条观测相比排名变化 ≥ 2 位。
- 每项返回图表、指标名、日期、当前值、`rank/(n+1)`、上一观测排名、`share_below`、较近 5 期均值，以及原因（`extreme_high` / `extreme_low` / `rank_change`）。排序：极端值在前，再按排名变化幅度。
- 读取按页面取数上限分批（每批 ≤ 256 个指标、合计 ≤ 20000 点）；单个图表失败时列入 `failed`，不影响其他图表。
- 展示在图表库顶部（可折叠的"本周同期异动"）和日报周报页的入口链接。只陈述位置与变化，不给方向判断。

## 三、问答读取图表库与周期对比

- 商品研究工具新增两个只读操作：
  - `charts`：按标题、分组或指标搜索图表库，返回图表 id、标题、模式和页面链接；
  - `cycle`：给定 `series_id`、可选 `template`（内置模板名或已保存模板 id）和 `date`，返回周期位置、往期区间、较近 5 期均值、往期后续汇总、省略周期与警告。不返回全部曲线点。
- 由模型根据完整问题选择指标、模板和日期，程序校验指标权限与参数后计算（`AGENTS.md`）。工具说明中注明"往期后续是历史参照，不是预测"。
- 研究服务 `/api/tools/read` 增加对应操作；WeKnora 工具 `commodity_research` 的参数枚举与字段同步扩展（需要重新编译后端）。
- 问答中画周期图、把问答图另存为图表放到三期。
