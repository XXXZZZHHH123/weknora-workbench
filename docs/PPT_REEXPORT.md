# 报告 PPT 导出、同期异动清单与问答读取

状态：新版报告 PPT 导出已实现，依赖 [图表库与周期对比](CHART_LIBRARY.md) 一期。是否已部署以目标环境实际验证为准。

## 一、一页周报与 PPT 导出

日报、周报以“本期综述 → 逻辑与策略 → 按维度分组的证据图 → 完整记录”组织。维度使用研究台自定义编号、名称与顺序；没有绑定、依据或研究员文字的维度不展示。综述复用研究维度页的真实观测与 `update_status` / `direction=no_update`：优先本期有更新的指标，再按同期极端、变化率绝对值排序，页面最多四项；整维度无更新时仅显示一句“本期无新数据（最新 YYYY-MM-DD）”和一至两个关键最新值参考，不将零差值写成持平。使用可读名称，未注明单位隐藏；结构化目录中 `field_metadata.role=annotation|text_dimension` 的字段不作为本期事实，也不交给模型起草。停更按该维度全部数值指标去重汇总为“N 项停更（最长 X 天）”，逐项日期、样本及读取限制默认折叠。页面五列为维度、本期变化、研究员一句话、影响、依据计数。

维度一句话、影响与图表结论可以由模型起草，但只进入编辑框，研究员保存后才生效。数字核对先剔除 facts 中原名、可读名及明确名称别名，避免名称内数字被当作观测值；名称比较规范化空白、全半角和斜杠分段。变化允许原正负号或方向词加同绝对值，方向相反仍拒绝；无更新输入保留状态及最新观测，不用历史差值起草本期变化。仅允许 facts 中的指标、数字和日期，独立第二次模型复核保留，异常标记待核对且不预填。与当前研判依据多数方向相反的显式影响选择仅提示复核，不修改研判。

导出窗口提供三种模式：**一页（默认）**、**一页 + 证据附录**、**完整记录**。默认直接输出 16:9 综述维度表与逻辑策略，不增加封面和说明页；周报标题包含起止日，日报包含单日。八维度优先保留一页，表格字号在 11–14pt、逻辑与策略在 11–13pt 内按内容量自适应，优先放大字号与行高使用可用空间。PPT 表格四列为维度、本期变化、研究员一句话、影响；只放研究台已配置维度，未标注或已删除维度的依据提示移入备注。维度列宽按最长名称计算，上限约 1.6 英寸，名称在列内完整换行，绝不省略；研究员一句话最多 60 字，影响标签与实际数据行垂直居中。表格高度取实际行高之和，逻辑区在其下方留出间距。无新数据在格内用浅灰小标签“无新数据 · 最新 YYYY-MM-DD”表示，其后至多列两个指标的名称、值与单位；有更新的指标照常显示变化。省略全文、停更明细和条件触发说明保留在演讲者备注的“全文附录”。“逻辑与策略”采用两栏：左侧复用报告页已选中的保存研判，显示状态日期、基调、主要矛盾及关键关注点，草稿也展示，报告页没有研判时才显示“暂无研判”；右侧每个方案最多三行，依次为方向与名称、核心逻辑、触发 → 应对，按宽度排布，超出部分截断并保留全文于备注。附录模式另以可见全文页保留被省略的内容；证据图按维度编排，每页一句结论和一到两张图。完整记录继续附上原研判、策略及旧按语。

- **内容来源**：服务端从与报告页面、Markdown、JSON 共用的报告视图重建。沿用已保存研判、策略与研究员按语，不接收客户端正文，不在导出时调用模型。保留当前条件状态、数据日期和过旧提示。条件触发不等于成交。
- **历史与缺口**：历史区间图只作对应窗口的证据，不将其旧窗口变化当作本期变化；不可用观测不补零。冻结归档保留归档内维度与事实，不重新读取当前指标。没有对应维度事实的图表保留人工结论，不生成无事实依据的模型结论。
- **版式**：13.333 × 7.5 英寸白底宽屏，中哲集团 logo、`#BE0008` 点缀和浅灰表头。中文 Microsoft YaHei，西文 Arial，一页表格 11–14pt、逻辑与策略 11–13pt；页脚标明数据截止日、工作台与页码。表格数字直接使用报告显示文本，不再次计算或换算。
- **图表**：浏览器通过既有逐图接口，以 ChartKit 白底样式绘制两倍像素 PNG；保持报告完整去重清单的 key 顺序。正文图表按维度分组，未找到归属的放“其他”。读取失败保留灰色占位与服务端核验提示；冻结归档不重读来源、不重新绘图，仅列原图标题与引用处。
- **接口**：`POST /api/sn/reports/{date}/{daily|weekly}/ppt`，multipart 的 `options` 为 JSON：`mode: one_page|evidence|full`（缺省一页）、`figures_per_slide: 1|2`（默认 2）。`mode` 与旧 `sections` 不可同时传入。旧客户端仅传 `sections: {summary,research,dashboard,watch}` 与 `figures_per_slide: 1|2|4` 的请求继续沿用原导出。其他字段为草稿 `revision`、有序 `keys`、重复 PNG `images` 和 `{key,reason}` 的 `failures`。一页模式 keys/images/failures 为空；附录模式提交完整报告图表清单；冻结归档不提交 images/failures。
- **权限与版本**：沿用既有读取权限及同源校验；受限视角 403，无研究台 409。服务端重新校验草稿版本、图表清单与顺序、真实 ID、固定修订及来源授权；变化返回 409“报告内容已变化，请刷新后重试”。隐藏部分不能通过导出重新开放。
- **上传与返回**：每张 PNG 最大 4 MiB、宽高各不超过 4000px，校验头部和完整解码；超大 413，损坏或数量不符 422。直接下载 PPTX，RFC 5987 文件名包含工作台、周期与日期；不写知识库、不保留导出文件，结束后关闭上传临时文件。

## 二、本周同期异动清单

- `GET /api/sn/charts/anomalies?date=&limit=`：对图表库中所有周期模式图表，在截止日计算周期位置，并在上一条观测日再算一次。
- 列入清单的条件：同期排名为前两高或前两低（往期有效段数 `n` ≥ 3）；或与上一条观测相比排名变化 ≥ 2 位。
- 每项返回图表、指标名、日期、当前值、`rank/(n+1)`、上一观测排名、`share_below`、较近 5 期均值，以及原因（`extreme_high` / `extreme_low` / `rank_change`）。排序：极端值在前，再按排名变化幅度。
- 读取按页面取数上限分批（每批 ≤ 256 个指标、合计 ≤ 20000 点）；单个图表失败时列入 `failed`，不影响其他图表。
- 展示在图表库顶部（可折叠的"本周同期异动"）和日报周报页的入口链接。只陈述位置与变化，不给方向判断。

## 三、问答读取图表库与周期对比

- 商品研究工具新增两个只读操作：
  - `charts`：按标题、分组或指标搜索图表库，返回图表 id、标题、模式和页面链接；
  - `cycle`：给定 `series_id`、可选 `template`（内置模板名或已保存模板 id）和 `date`，返回周期位置、往期区间、较近 5 期均值、往期后续汇总、省略周期与警告。不返回全部曲线点。
- 由模型根据完整问题选择指标、模板和日期，程序校验指标权限与参数后计算（`AGENTS.md`）。工具说明中注明"往期后续是历史参照，不是预测"。
- 研究服务 `/api/tools/read` 增加对应操作；WeKnora 工具 `commodity_research` 的参数枚举与字段同步扩展（需要重新编译后端）。
- 问答中画周期图、把问答图另存为图表放到三期。
