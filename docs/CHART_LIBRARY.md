# 图表库与周期对比

状态：一期设计，开发中。本文是实现规格与验收依据；是否已部署以目标环境实际验证为准。

## 背景与定位

研究员的周报以"今年对比往年同期"的周期图为主，原表中大量图表靠手工按年份切分单元格区间维护，每增加一年都要手工补一段。平台此前只把数据画成单条走势线，问答图表只保存为 PNG 附件，原表图表只作为只读索引。

本功能把图表做成平台内可保存、可复用、随数据更新的对象，并提供通用的周期对比计算：

- 图表是定义，不是图片：记录曲线、指标、图型、坐标轴、样式和时间范围，打开时按当前数据重画。
- 周期是一组带起点和终点的时间段；季节只是"每年固定日期起、长度一年"的特例。
- 只做确定性计算与展示，不做方向预测、打分、参数寻优或交易建议；"往期后续"逐期列出并标明样本数。
- 研究员原表中的图表可以迁移为平台图表，转换建议需研究员按工作表确认一次。

## 约束

- 遵守 `AGENTS.md` 问答实现约束：不按指标名、文件名、工作表名或特定问题写规则；转换和检测只依据结构（同一指标、时间段是否互不重叠）与真实日期。字面匹配只能作为候选证据。
- 不填零、不插值、不补造日期；缺失观测断开曲线。
- 不同单位不放在同一根纵轴；不自动换算单位。
- 图表缓存值、OCR 结果不作为数据。
- 一期只支持来源版本 2 的研究台（`scope_version == 2`）；旧来源授权返回 409 并提示重新打开研究台。受限视角（`scope.restricted`）一期不开放图表库读写，返回 403。

## 一、周期对比计算（研究服务 `tin/compute/cycles.py`）

纯函数模块，不访问数据库，输入为一条序列的有效观测 `[(date, value)]`（升序、同日只保留一条）。

### 周期模板

| kind | 字段 | 说明 |
|---|---|---|
| `repeat` | `start`（`MM-DD`）、`period`（`year`/`half`/`quarter`/`month`） | 按规则重复。`year` 从每年 `start` 起一年；`month` 只用 `start` 的日。 |
| `event` | `calendar`（`spring_festival`）或 `anchors`（`[{label, date}]`）、`before_days`、`after_days` | 以事件日为零点，取前后窗口。 |
| `segments` | `segments`（`[{label, start, end}]`，1–40 段） | 手动列出时间段，长度可不同，允许重叠但要在结果中提示。 |

模板通用字段：`name`（≤40 字）、`align`（一期仅 `days`：距起点或事件日的自然日数）、`transform`（`raw` 原值、`change` 相对起点变化、`rebase` 起点=100）。

`spring_festival` 使用固定日历表（2000–2030 年春节公历日期，属于日历事实数据）：

```
2000-02-05 2001-01-24 2002-02-12 2003-02-01 2004-01-22 2005-02-09 2006-01-29 2007-02-18
2008-02-07 2009-01-26 2010-02-14 2011-02-03 2012-01-23 2013-02-10 2014-01-31 2015-02-19
2016-02-08 2017-01-28 2018-02-16 2019-02-05 2020-01-25 2021-02-12 2022-02-01 2023-01-22
2024-02-10 2025-01-29 2026-02-17 2027-02-06 2028-01-26 2029-02-13 2030-02-03
```

内置模板（代码常量，不入库）：`自然年`（repeat 01-01 year）、`春节前后8周`（event spring_festival，前后各 56 天）。

### 计算规则

1. **频率**：按实际观测日期的相邻正间隔中位数得到 `freq_days`；同一位置的匹配容差 `tol = max(1, floor(freq_days / 2))` 天。不从指标名或元数据猜频率。
2. **分段**：repeat 从第一条观测所在周期生成到截止日所在周期；event 只取窗口内有观测的事件；segments 按给定。生成后省略截止日（含）之前没有任何观测的段，在 `omitted_segments` 中按生成顺序记录原样标签，并在 `warnings` 中加入一次 `empty_segments_omitted`；没有省略时返回空列表且不加此提示。省略发生在展示周期数截取之前，空段不占展示期数；有观测但变换值不可用的段仍保留。每段标签：repeat 年周期起点为 1 月 1 日时用 `2023`，否则用 `23/24`；event 用事件年份；segments 用给定标签（原样，不解释含义）。
3. **对齐**：横轴 `x` = 观测日期距段起点（event 为事件日）的天数。
4. **变换**：`change`/`rebase` 以段内第一条观测为基准；若第一条观测晚于段起点超过 `tol`，该段标记 `start_missing`，不参与变换后的统计。`rebase` 基准为 0 或负数时该段不可用。
5. **当前段与当前位置**：截止日之前最新观测所在的段为当前段，其 `x` 为当前位置 `x*`。
6. **往期同位置值**：每个往期段取 `x` 与 `x*` 最接近且差值 ≤ `tol` 的观测；没有则该段在此位置缺失。
7. **覆盖率**：段内观测数 / (有效段长 / `freq_days`) < 0.5 的段标记 `sparse`，不参与统计，但仍可显示。有效段长为段起点到"段终点与截止日中较早者"的天数（含首尾）；未走完的当前段只按已经过去的天数计算。
8. **统计**（往期有效段数 `n` < 3 时只返回曲线，统计返回 `insufficient_cycles`）：
   - 排名：当前值在"往期同位置值 + 当前值"中从高到低的名次 `rank/(n+1)`；
   - `share_below`：往期同位置值中低于当前值的比例；
   - 往期同位置的最小、最大、中位数、均值；
   - 较最近 5 个往期均值：`raw` 且均值为正时给出百分比，否则给出差值；
   - 区间带：覆盖整个周期，不只到当前位置。`repeat` 与 `segments` 取 `x = 0, freq_days, 2·freq_days, …` 直到最长往期段的长度；`event` 取 `-before_days` 到 `after_days`，同样按 `freq_days` 步进（`freq_days` 非整数时四舍五入，至少 1）。每个 `x` 取最近 `band_cycles`（默认 5）个有效往期段在容差内的值，算最小、最大、均值并给出 `n`；`n` 为 0 的点不输出。
9. **往期后续**：对每个有同位置值的往期段，取其匹配日期 `d0` 之后 `h × freq_days` 天（`h` 默认 4、8、12）最接近且差值 ≤ `tol` 的观测（可以跨入下一段），给出变化值与变化率；汇总中位数、最小、最大、上涨段数 / 有效段数。不输出概率或预测值。
10. **截止日**：所有计算只使用截止日（含）之前的观测。

## 二、原表图表研究读取（结构化数据服务）

新增 `POST /api/research/native-charts`，沿用 `/api/research/facts` 的研究台来源核验（`request.state.research_sources`、`verify_research_projection`、读取期间来源变化即拒绝），只返回当前已批准来源对应数据集的原生图表。

请求：`{"offset": 0, "limit": 200}`（limit 1–200）。

响应：

```json
{"charts": [{
   "chart_key": "nc-<sha256(knowledge_base_id, knowledge_id, chart_id) 前32位>",
   "knowledge_id": "...", "source_file": "...", "sheet": "...", "title": "...",
   "axes": [{"id": "...", "type": "dateAx|catAx|valAx", "title": "(元/吨)", "position": "l|r|b|t|null"}],
   "curves": [{"label": "2016", "chart_type": "lineChart|barChart|areaChart|...", "axis": "primary|secondary",
               "series_id": "kb-...|null", "status": "linked|pending_source|unsupported|no_data|unconfirmed_sheet",
               "reason": "...", "first_date": "...", "last_date": "...", "unit": "...",
               "descriptor": {"sheet": "...", "metric": "...", "column": "M", "start_row": 3, "end_row": 368},
               "style": {"color": "#C00000|null", "width_pt": 2.25, "dash": "solid|dash|dot|null"}}]}],
 "total": 721, "offset": 0, "next_offset": 200}
```

- `series_id` 使用与研究事实相同的 `kb-` 身份算法，且只在曲线源字段属于已确认工作表时给出；否则 `status=unconfirmed_sheet`。

## 三、图表定义（研究服务 `tin/schemas/chart.py`）

`format: "chart.v1"`，JSON 存入 `workbench_artifacts`（`module = "charts"`），在研究台内共享：任何有查看权限的成员可读，写入需共享写权限（同 `structure` 模块的 `require_shared_write`）。每次修改递增 `revision` 并写入修订历史；更新必须携带当前 `revision`，不一致返回 409。删除为状态 `deleted`。

```json
{
  "format": "chart.v1",
  "title": "纯棉纱负荷",            // 1–120 字
  "group": "TTEB下游情况(图)",       // 0–80 字，可选
  "note": "",                        // 0–600 字
  "curves": [{                        // 1–16 条
    "series_id": "kb-...",
    "label": "纯棉纱负荷",
    "kind": "line|bar|area",
    "axis": "left|right",
    "style": {"color": "#C00000", "width": 2, "dash": "solid|dash|dot"},
    "descriptor": {"source_file": "...", "sheet": "...", "metric": "...", "column": "M"}
  }],
  "time": {"mode": "recent", "points": 120}
       | {"mode": "since", "start": "2016-01-01"}
       | {"mode": "range", "start": "...", "end": "..."}
       | {"mode": "cycle", "template": {...}, "cycles": 8, "band_cycles": 5, "transform": "raw",
          "segment_styles": [{"label": "2023", "color": "#C00000", "width": 2.25, "dash": "solid"}]},
  "axes": {"left": {"min": null, "max": null}, "right": {"min": null, "max": null}},
  "origin": {"kind": "manual|native|chat|ppt", "ref": "nc-..."}
}
```

校验：

- `series_id` 必须在当前研究台目录中存在（经目录读取核验），否则拒绝保存；已保存图表中失效的曲线在读取时标记 `missing`，不静默删除。
- 同一根纵轴上的曲线单位必须一致；单位缺失的曲线单独提示，不阻止保存。
- `cycle` 模式一期限 1 条曲线。
- `cycle.segment_styles` 可选，默认空列表，最多 40 项；每项 `label` 为 1–40 字，`color` 为 `#RRGGBB` 或 `null`，`width`、`dash` 沿用曲线样式校验（可省略或为 `null`）。仅当渲染段标签与 `label` 完全相等时应用，不裁剪空白、不解析年份或按顺序猜测映射；未匹配的段使用默认配色与样式。编辑周期设置时保留此列表。
- `descriptor` 用于来源失效后的重新绑定候选，只作提示，不自动改绑。

周期模板可另存为共享对象（`module = "cycle_templates"`），结构同上文模板，权限规则同图表。

## 四、原表图表转换（研究服务）

读取第二节接口，按以下结构规则给出转换建议，不按名称判断：

1. 只考虑 `status=linked` 的曲线；一张图没有任何可用曲线时不转换，列入"无法转换"并说明原因。
2. **分段检测**：在可用曲线中找曲线数最多的同一 `series_id` 组（并列取图中先出现者）；该组有 ≥3 条曲线且起点 `first_date` 互不相同，判定为周期图。图中其他指标的曲线不转换，列入缺失曲线，原因写"周期图一期只保留一个指标"。只看起点：原表中较新年份的曲线常引用到表尾的开放区间（如 `M2560:M9996`），靠横轴类别数只显示一个周期，所以曲线的引用区间会互相包含，不能用"区间不重叠"判断。
   - 相邻起点间隔的中位数在 330–400 天，且每个间隔都在 300–430 天之间：建议 `repeat` / `year`，起点取各曲线起点中出现最多的月份（并列取最早出现者）的 1 日（例如 2017-09-01、2018-09-01、2021-08-31 → 09-01），`cycles` = 曲线条数。
   - 否则：建议 `segments`，每段从曲线起点到"自身 `last_date` 与下一段起点前一天"中较早者，最后一段到自身 `last_date`，标签取原始图例。
   - 图例只作为段标签原样保留，不解释为年份或合约。
3. 其余情况转换为走势图：`time.mode = since`，起点为各曲线最早 `first_date`，终点不固定，数据增加后自动延长。
4. 保留曲线图型、左右轴、顺序与样式；周期模式保留的一条指标曲线，其 `label` 取当前来源目录的 `metric`，缺失时取图表标题，曲线相关提示也使用此名称，不显示 `kb-` 编号。原表每期图例原样写入 `time.segment_styles[].label`，各自颜色、线宽（`width_pt` 转为 `width`）与虚线写入对应样式，不解释图例含义。有部分曲线不可用时照常转换，并在 `note` 和预览中列出缺失曲线。
5. **原图缺最新周期提示**：`repeat` 周期图的源序列在"最后一条曲线起点 + 1 个周期"当天或之后已有观测时，在预览中提示"原图未包含 ××，转换后会显示"。
6. 预览按工作表分组，每表先列可转换图；无法转换的图置于默认折叠的 `<details>` 中，标题为"N 张无法转换，展开查看原因"。汇总按周期起点合并计图表张数，不按展示期数拆分，例如"本表 133 张：46 张周期图（起点 01-01 30 张、起点 09-01 12 张、原表分段 4 张），1 张走势图，86 张无法转换"；跨页合并同一工作表后重新汇总。研究员按工作表勾选确认，可整表修改周期起点后再确认。
7. 应用转换时以 `origin.ref = chart_key` 去重；已转换过的图表不重复创建。

已知限制：原表中"一列日期 + 每年单独一列"的季节图排法，各年列对应不同指标序列，按结构会转换为走势图，显示效果与季节图相同；新的一年不会自动出现，需要研究员在原表新增列后重新导入。相同 `origin.ref` 仍遵守去重规则，已有图表定义不会自动增加新曲线。

## 六、页面

- **图表组件** `static/chart-kit.js`：原生 JavaScript + SVG；支持线、柱、面积，左右双轴，日期轴；自动纵轴采用 `1/2/5 × 10^n` 步长，刻度按步长精度格式化（如 `20`、`40` 或 `0.5`、`1.0`），缩略图最多 4 个，大图 5–7 个；手工纵轴范围保持原值，仅显示范围内的刻度。周期模式下横轴为距起点天数，刻度按模板起点换算成月份或周；段标签完全匹配 `segment_styles` 时使用其中颜色、线宽、虚线，未指定的属性使用默认值；默认当前段使用曲线颜色（缺失时用强调色）与粗线，上一段虚线，更早段使用调色板中不同颜色的淡色细线。月度数据在周期图中按所在月份居中显示，悬停显示真实日期。图例与对应线条颜色、线宽、虚线和淡化程度一致；无有效点的段不画线、不列图例或悬停项。最近 `band_cycles` 期最小–最大灰带与均值线；悬停显示该位置各段的值；图例可点击显隐；缺失观测断线；走势图颜色使用图表定义样式，未设置时用现有调色板；支持"复制为图片"（SVG 转 PNG）和"下载 SVG"。一期只在新页面使用，不替换已有的四处画图代码。
- **图表库** `/sn/indicators?tab=charts`：按分组、搜索浏览，卡片懒加载缩略图；卡片提示显示为标题旁带 `title` 说明的小标记。旧入口 `/sn/charts` 保留查询参数并跳转到指标页图表栏。进入详情 `/sn/charts/{id}`：大图、图下方一行小字提示、周期统计（排名、区间、较近 5 期均值、往期后续表）、编辑定义、修订历史。
- **原表导入** `/sn/charts/import`：按工作表展示转换建议，批量确认。
- **单指标页**：新增"周期对比"面板（模板下拉：内置 + 已保存；排名、往期区间、较近 5 期均值、往期后续逐期列表并标样本数）、"相关图表"（包含该指标的已保存图表）、"另存为图表"；"被谁在用"中加入图表引用数。
- 导航保留"指标"，图表库统一放在指标页图表栏；卡片与详情可加入账号自选，见 [指标页三栏、自选与核心关注](WATCHLIST_AND_FOCUS.md) 第一、二节。
