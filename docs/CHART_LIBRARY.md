# 图表库与周期对比

状态：一期设计，开发中。本文是实现规格与验收依据；是否已部署以目标环境实际验证为准。

## 背景与定位

研究员的周报以"今年对比往年同期"的周期图为主，原表中大量图表靠手工按年份切分单元格区间维护，每增加一年都要手工补一段。平台此前只把数据画成单条走势线，问答图表只保存为 PNG 附件，原表图表只作为只读索引。

本功能把图表做成平台内可保存、可复用、随数据更新的对象，并提供通用的周期对比计算：

- 图表是定义，不是图片：记录曲线、指标、图型、坐标轴、样式和时间范围，打开时按当前数据重画。
- 周期是一组带起点和终点的时间段；季节只是"每年固定日期起、长度一年"的特例。
- 只做确定性计算与展示，不做方向预测、打分、参数寻优或交易建议；"往期后续"逐期列出并标明样本数。
- 研究员原表中的图表可以迁移为平台图表，转换建议需研究员按工作表确认一次。

## 约束

- 遵守 `AGENTS.md` 问答实现约束：不按指标名、文件名、工作表名或特定问题写规则；转换和检测只依据结构（同一指标、时间段是否互不重叠）与真实日期。字面匹配只能作为候选证据。
- 不填零、不插值、不补造日期；缺失观测断开曲线。
- 不同单位不放在同一根纵轴；不换算原始数据。显示时可按量级使用千分位、万或亿，轴标题或图例保留原单位，并明确标出显示倍率（如“万手”）。
- 图表缓存值、OCR 结果不作为数据。
- 一期只支持来源版本 2 的研究台（`scope_version == 2`）；旧来源授权返回 409 并提示重新打开研究台。受限视角（`scope.restricted`）一期不开放图表库读写，返回 403。

## 一、周期对比计算（研究服务 `tin/compute/cycles.py`）

纯函数模块，不访问数据库，输入为一条序列的有效观测 `[(date, value)]`（升序、同日只保留一条）。

### 周期模板

| kind | 字段 | 说明 |
|---|---|---|
| `repeat` | `start`（`MM-DD`）、`period`（`year`/`half`/`quarter`/`month`） | 按规则重复。`year` 从每年 `start` 起一年；`month` 只用 `start` 的日。 |
| `event` | `calendar`（`spring_festival`）或 `anchors`（`[{label, date}]`）、`before_days`、`after_days` | 以事件日为零点，取前后窗口。 |
| `segments` | `segments`（`[{label, start, end}]`，1–40 段） | 手动列出时间段，长度可不同，允许重叠但要在结果中提示。 |

模板通用字段：`name`（≤40 字）、`align`（一期仅 `days`：距起点或事件日的自然日数）、`transform`（`raw` 原值、`change` 相对起点变化、`rebase` 起点=100）。

`spring_festival` 使用固定日历表（2000–2030 年春节公历日期，属于日历事实数据）：

```
2000-02-05 2001-01-24 2002-02-12 2003-02-01 2004-01-22 2005-02-09 2006-01-29 2007-02-18
2008-02-07 2009-01-26 2010-02-14 2011-02-03 2012-01-23 2013-02-10 2014-01-31 2015-02-19
2016-02-08 2017-01-28 2018-02-16 2019-02-05 2020-01-25 2021-02-12 2022-02-01 2023-01-22
2024-02-10 2025-01-29 2026-02-17 2027-02-06 2028-01-26 2029-02-13 2030-02-03
```

内置模板（代码常量，不入库）：`自然年`（repeat 01-01 year）、`春节前后8周`（event spring_festival，前后各 56 天）。

### 计算规则

1. **频率**：按实际观测日期的相邻正间隔中位数得到 `freq_days`；同一位置的匹配容差 `tol = max(1, floor(freq_days / 2))` 天。不从指标名或元数据猜频率。
2. **分段**：repeat 从第一条观测所在周期生成到截止日所在周期；event 只取窗口内有观测的事件；segments 按给定。生成后省略截止日（含）之前没有任何观测的段，在 `omitted_segments` 中按生成顺序记录原样标签，并在 `warnings` 中加入一次 `empty_segments_omitted`；没有省略时返回空列表且不加此提示。省略发生在展示周期数截取之前，空段不占展示期数；有观测但变换值不可用的段仍保留。每段标签：repeat 年周期起点为 1 月 1 日时用 `2023`，否则用 `23/24`；event 用事件年份；segments 用给定标签（原样，不解释含义）。
3. **对齐**：横轴 `x` = 观测日期距段起点（event 为事件日）的天数。
4. **变换**：`change`/`rebase` 以段内第一条观测为基准；若第一条观测晚于段起点超过 `tol`，该段标记 `start_missing`，不参与变换后的统计。`rebase` 基准为 0 或负数时该段不可用。
5. **当前段与当前位置**：截止日之前最新观测所在的段为当前段，其 `x` 为当前位置 `x*`。
6. **往期同位置值**：每个往期段取 `x` 与 `x*` 最接近且差值 ≤ `tol` 的观测；没有则该段在此位置缺失。
7. **覆盖率**：段内观测数 / (有效段长 / `freq_days`) < 0.5 的段标记 `sparse`，不参与统计，但仍可显示。有效段长为段起点到"段终点与截止日中较早者"的天数（含首尾）；未走完的当前段只按已经过去的天数计算。
8. **统计**（往期有效段数 `n` < 3 时只返回曲线，统计返回 `insufficient_cycles`）：
   - 排名：当前值在"往期同位置值 + 当前值"中从高到低的名次 `rank/(n+1)`；
   - `share_below`：往期同位置值中低于当前值的比例；
   - 往期同位置的最小、最大、中位数、均值；
   - 较最近 5 个往期均值：`raw` 且均值为正时给出百分比，否则给出差值；
   - 区间带：覆盖整个周期，不只到当前位置。`repeat` 与 `segments` 取 `x = 0, freq_days, 2·freq_days, …` 直到最长往期段的长度；`event` 取 `-before_days` 到 `after_days`，同样按 `freq_days` 步进（`freq_days` 非整数时四舍五入，至少 1）。每个 `x` 取最近 `band_cycles`（默认 5）个有效往期段在容差内的值，算最小、最大、均值并给出 `n`；`n` 为 0 的点不输出。
9. **往期后续**：对每个有同位置值的往期段，取其匹配日期 `d0` 之后 `h × freq_days` 天（`h` 默认 4、8、12）最接近且差值 ≤ `tol` 的观测（可以跨入下一段），给出变化值与变化率；汇总中位数、最小、最大、上涨段数 / 有效段数。不输出概率或预测值。
10. **截止日**：所有计算只使用截止日（含）之前的观测。

## 三、图表定义（研究服务 `tin/schemas/chart.py`）

`format: "chart.v1"`，JSON 存入 `workbench_artifacts`（`module = "charts"`），在研究台内共享：任何有查看权限的成员可读，写入需共享写权限（同 `structure` 模块的 `require_shared_write`）。每次修改递增 `revision` 并写入修订历史；更新必须携带当前 `revision`，不一致返回 409。删除为状态 `deleted`。

```json
{
  "format": "chart.v1",
  "title": "纯棉纱负荷",            // 1–120 字
  "group": "TTEB下游情况(图)",       // 0–80 字，可选
  "note": "",                        // 0–600 字
  "curves": [{                        // 1–16 条
    "series_id": "kb-...",           // 与 derived 二选一
    "label": "纯棉纱负荷",
    "kind": "line|bar|area",
    "axis": "left|right",
    "curve_cycles": "current|current_and_previous", // 多指标周期图可逐曲线覆盖 time.curve_cycles
    "style": {"color": "#C00000", "width": 2, "dash": "solid|dash|dot"},
    "descriptor": {"source_file": "...", "sheet": "...", "metric": "...", "column": "M"}
  }],
  "time": {"mode": "recent", "points": 120, "transform": "raw|change|rebase"}
       | {"mode": "since", "start": "2016-01-01", "transform": "raw|change|rebase"}
       | {"mode": "range", "start": "...", "end": "...", "transform": "raw|change|rebase"}
       | {"mode": "cycle", "template": {...}, "cycles": 8, "visible_cycles": 5, "band_cycles": 5, "transform": "raw",
          "curve_cycles": "current",
          "segment_styles": [{"label": "2023", "color": "#C00000", "width": 2.25, "dash": "solid"}]},
  "axes": {"left": {"min": null, "max": null}, "right": {"min": null, "max": null}},
  "origin": {"kind": "manual|native|chat|ppt", "ref": "nc-..."}
}
```

校验：

- 每条曲线必须且只能设置 `series_id` 或 `derived`。所有直接指标与公式操作数 ID 必须在当前研究台目录中存在（经目录读取核验），否则拒绝保存；已保存图表中失效的曲线在读取时标记 `missing`，不静默删除。列表的 `series_id` 筛选也包含公式操作数引用。
- 同一根纵轴上的曲线单位必须一致；单位缺失的曲线单独提示，不阻止保存。
- `cycle` 支持 1–8 条曲线；一条曲线沿用历史多周期对比、显隐、区间带和统计。2–8 条曲线共用模板和周期横轴，`time.curve_cycles` 为 `"current" | "current_and_previous"`，默认 `current`；各曲线同名可选字段覆盖该默认值。`current_and_previous` 仅显示真实当前期与紧邻上一期，上一期虚线。缺少上一期观测时不拿更早周期代替。
- 多指标共用最近实际观测所属的当前周期；某指标在该共同周期没有观测时，显示当前期缺失，统计不借用该指标更早周期冒充当前期。每个指标仍用自己的实际观测频率、匹配容差和有效历史计算统计。返回 `mode: "cycle"`、共同 `template`、`common_current_start` / `common_previous_start` 和 `curves`；每项保留曲线元数据，`cycle` 子对象为第一节完整输出。顶层及各曲线不输出区间带。单指标保留原响应格式。
- 原值模式下，同单位使用同轴，第二种单位使用右轴；超过两种单位提示研究员变换或调整曲线，不做单位换算。`rebase` 将各曲线规范到起点=100；`change` 为减去各自起点的变化值，仍保留原单位并遵守单位轴规则。走势模式同样支持这些变换，先执行用户时间范围裁剪，再取每条曲线首条有效观测作为基准；`rebase` 基准不为正时提示且不产生有效变换值。
- `cycle.visible_cycles`（定义中的 `time.visible_cycles`）可选，严格整数 1–40，表示首次绘制时可见的总期数；缺省显示当前段、上一段及额外最多 3 个最近往期段（共最多 5 期）。按实际段起点倒序选择，不解析标签；隐藏期仍保留在数据与图例中，可逐条点开或使用“显示全部年份”开关。此项不改变 `cycles` 取数范围、区间带或统计。
- `cycle.segment_styles` 可选，默认空列表，最多 40 项；每项 `label` 为 1–40 字，`color` 为 `#RRGGBB` 或 `null`，`width`、`dash` 沿用曲线样式校验（可省略或为 `null`）。仅当渲染段标签与 `label` 完全相等时应用，不裁剪空白、不解析年份或按顺序猜测映射；未匹配的段使用默认配色与样式。编辑周期设置时保留此列表。
- `descriptor` 用于来源失效后的重新绑定候选，只作提示，不自动改绑。

### 计算序列

曲线可由研究员明确选择两个真实指标，保存如下公式和自定义图例（不保存计算结果）：

```json
{"derived": {"op": "sub", "a": "kb-...", "b": "kb-...", "unit_confirmed": false}, "label": "研究员填写的图例", "axis": "left"}
```

- `op` 只允许 `sub` 或 `div`；`a`、`b` 为当前研究台真实指标 ID，不允许嵌套公式、表达式文本或自行编造 ID。
- 读取时只在两者都有有效观测的相同日期计算，不插值、不补点。除数为零、计算溢出等不可用结果不成为有效观测。
- `sub` 要求非空单位完全一致，不做换算。任一操作数单位缺失时返回确认提示，研究员明确勾选后设置 `derived.unit_confirmed: true` 才可预览或保存；该确认不能放行两个已知但不一致的单位。单位缺失提示保留。
- `div` 的结果单位固定为“倍”。计算序列可用于走势或周期模式；周期统计、近期均值与往期后续同样只用实际计算得到的有效日期。
- 每次读取仍通过 `page_read_scope('indicators', …)` 读取真实操作数；每个操作数最多 `min(2000, floor(20000 / max(定义曲线数, 去重操作数数)))` 点，较小的 `recent.points` 继续生效。重复和失效曲线保留原定义点数上限约束；不会因为只显示一个公式而越过 20000 点预算。

### 依据指标作图与图集

单指标页“作图”默认选中该指标并打开周期对比；指标目录和自选中的指标可多选后作图；图表栏提供“新建图表”。面板可搜索当前目录、从自选快捷选择，最多选择 16 个指标；研究员选择周期、走势或批量周期图，并预览后保存，选择已有分组或输入新分组，保存后可加入账号自选。多指标周期对比上限 8 条曲线，走势上限 16 条。

单指标默认周期模板只从当前已保存、未删除的原表导入周期图定义读取：要求 `origin.kind == native` 且 `origin.ref` 非空，`time.template.kind == repeat`，曲线 `descriptor.source_file`、`descriptor.sheet` 与目标指标目录元数据完全相同，并通过实际绑定 ID 核对 `source_knowledge_id`、`dataset_id`、`source_binding_id` 同源。按明确的 `template.start` 统计图表张数，取出现最多的模板起点；若同起点存在多种 `period`，再取该起点最常见的 `period`；并列取最早保存的定义。原表分段图没有通用重复起点，不推断起点；缺少上述证据时回到自然年。指标名、图表标题、分组名或关键词不参与默认选择。

批量周期图一次为每个所选指标创建一张单指标周期图，要求共用一个非空分组，最多 16 张。未显式覆盖模板时，各指标按上述规则单独取默认值；确认保存前整组校验，任一 ID 无效则整组不写入。图表栏选择分组后复用既有卡片和懒加载整组平铺。批量预览同一请求的底层观测总预算不超过 20000 点；图集保存后仍只保存定义。

周期模板可另存为共享对象（`module = "cycle_templates"`），结构同上文模板，权限规则同图表。

## 四、原表图表转换（研究服务）

读取第二节接口，按以下结构规则给出转换建议，不按名称判断：

1. 只考虑 `status=linked` 的曲线；一张图没有任何可用曲线时不转换，列入"无法转换"并说明原因。
2. **分段检测**：在可用曲线中找曲线数最多的同一 `series_id` 组（并列取图中先出现者）；该组有 ≥3 条曲线且起点 `first_date` 互不相同，判定为周期图。图中其他指标的曲线不转换，列入缺失曲线，原因写"周期图一期只保留一个指标"。只看起点：原表中较新年份的曲线常引用到表尾的开放区间（如 `M2560:M9996`），靠横轴类别数只显示一个周期，所以曲线的引用区间会互相包含，不能用"区间不重叠"判断。
   - 每个相邻起点间隔都接近整数个年度（`k × 365` 天，误差不超过 ±35 天，整数 `k ≥ 1`）：建议 `repeat` / `year`，允许原图缺少部分年度，不再要求起点间隔中位数为一年。起点仍取各曲线起点中出现最多的月份（并列取最早出现者）的 1 日（例如 2017-09-01、2018-09-01、2021-08-31 → 09-01），`cycles` = 曲线条数。计算继续仅使用真实观测；缺失年度不补造，无观测段省略。
   - 否则：建议 `segments`，每段终点先取“自身 `last_date` 与下一段起点前一天”中较早者，最后一段先取自身 `last_date`。若相邻起点间隔中位数不超过 400 天，再将每段终点限制为不晚于“该段起点 + 中位数天”（不足整日向下取整），包括最后一段；中位数超过 400 天时不增加此上界。标签取原始图例。
   - 图例只作为段标签原样保留，不解释为年份或合约。
3. 其余情况转换为走势图：`time.mode = since`，起点为各曲线最早 `first_date`，终点不固定，数据增加后自动延长。
4. 保留曲线图型、左右轴、顺序与样式；周期模式保留的一条指标曲线，其 `label` 取当前来源目录的 `metric`，缺失时取图表标题，曲线相关提示也使用此名称，不显示 `kb-` 编号。原表每期图例原样写入 `time.segment_styles[].label`，各自颜色、线宽（`width_pt` 转为 `width`）与虚线写入对应样式，不解释图例含义。有部分曲线不可用时照常转换，并在 `note` 和预览中列出缺失曲线。
5. **原图缺最新周期提示**：`repeat` 周期图的源序列在"最后一条曲线起点 + 1 个周期"当天或之后已有观测时，在预览中提示"原图未包含 ××，转换后会显示"。
6. 预览按工作表分组，每表先列可转换图；无法转换的图置于默认折叠的 `<details>` 中，标题为"N 张无法转换，展开查看原因"。汇总按周期起点合并计图表张数，不按展示期数拆分，例如"本表 133 张：46 张周期图（起点 01-01 30 张、起点 09-01 12 张、原表分段 4 张），1 张走势图，86 张无法转换"；跨页合并同一工作表后重新汇总。研究员按工作表勾选确认，可整表修改周期起点后再确认。
7. 应用转换时以 `origin.ref = chart_key` 去重；已转换过的图表不重复创建。
8. 新规则不自动改写已保存定义。原表导入图的详情提供“按原表重新转换”：用 `origin.ref` 在当前已授权来源中重新读取原表图表，再按当前规则生成建议；预览不落库。研究员查看并明确确认后，携带预览时的 `revision` 通过现有修改接口保存为新修订，保留旧修订；期间发生修改返回 409。原表图已失效、当前来源不允许读取或建议不可转换时说明原因，不改绑其他图表。

已知限制：原表中"一列日期 + 每年单独一列"的季节图排法，各年列对应不同指标序列，按结构会转换为走势图，显示效果与季节图相同；新的一年不会自动出现，需要研究员在原表新增列后重新导入。相同 `origin.ref` 仍遵守去重规则，已有图表定义不会自动增加新曲线。

## 六、页面

- **图表组件** `static/chart-kit.js`：原生 JavaScript + SVG，页面与 PPT 导出共用；支持线、柱、面积，左右双轴，日期轴。显示规则如下：
  - 日期轴按跨度选择年、季、月、周、日，以真实日历边界取整，标签如 `2016`、`2016-07`、`07-15`，不使用时间范围均分产生的零碎日期。
  - 自动纵轴采用 `1/2/5 × 10^n` 步长，刻度小数位按步长确定，缩略图最多 4 个，大图 5–7 个；坐标轴、悬停与末端值按量级使用千分位、万或亿（如 `200000 → 20万`）。单位保持真实来源单位，显示倍率需明确；仅改变文字，不改变点值。手工纵轴范围保持原值，仅显示范围内的刻度。双轴使用相同网格数与纵向位置，右轴标签跟随右轴曲线颜色。
  - 周期横轴为距起点天数，repeat 刻度按模板起点换算成月份，event 用相对周；segments 仅当所有段长度均在 300–400 天时按第一段起点显示月份（如 `8月…7月`），否则显示“第 N 天”。月度数据按所在月份居中，悬停仍显示真实日期。
  - 段标签完全匹配 `segment_styles` 时使用其中颜色、线宽、虚线，未指定属性使用默认值。默认当前段使用曲线颜色（缺失时用强调色）与粗线，上一段虚线，更早段为淡色细线；默认显隐遵循 `visible_cycles`，图例可点开隐藏段，“显示全部年份”开关可显示全部段，区间带不随显隐改变。图例与对应曲线样式一致；无有效点的段不画线、不列图例或悬停项。
  - 周期图在当前段最新点旁标注数值，悬停列出该位置各年真实值，按数值从高到低排列，当前段加粗，缺失位置明确提示。走势图在每条曲线末端标注最新值；空间不足时优先只标注左轴主曲线。
  - 最近 `band_cycles` 期最小–最大灰带与均值线保持原规则；缺失观测断线。走势图沿用定义颜色或默认调色板；支持“复制为图片”（SVG 转 PNG）和“下载 SVG”。一期只在新页面使用，不替换已有的四处画图代码。
  - 多指标周期图按指标保留颜色，当前期实线、上一期同色虚线，左右轴按单位分配，禁用区间带；图例包括研究员填写的计算序列名称。统计面板按曲线逐行列出同期排名与较近 5 期均值（含实际样本数）。
- **图表库** `/sn/indicators?tab=charts`：按分组、搜索浏览，卡片懒加载缩略图；卡片提示显示为标题旁带 `title` 说明的小标记。旧入口 `/sn/charts` 保留查询参数并跳转到指标页图表栏。进入详情 `/sn/charts/{id}`：大图、图下方一行小字提示、周期统计（排名、区间、较近 5 期均值、往期后续表）、编辑定义、修订历史。
- **原表导入** `/sn/charts/import`：按工作表展示转换建议，批量确认。
- **单指标页**：新增"周期对比"面板（模板下拉：内置 + 已保存；排名、往期区间、较近 5 期均值、往期后续逐期列表并标样本数）、"相关图表"（包含该指标的已保存图表）、"另存为图表"；"被谁在用"中加入图表引用数。
- 导航保留"指标"，图表库统一放在指标页图表栏；卡片与详情可加入账号自选，见 [指标页三栏、自选与核心关注](WATCHLIST_AND_FOCUS.md) 第一、二节。

## 七、分期

研判与策略现支持显式引用共享图表，保存时冻结图表修订、来源版本与研究日期；历史默认按原修订及截止日渲染，可切换当前数据，规则阈值与相关图表只按真实指标 ID 关联。底层来源不提供旧事实版本回放时，来源更新会明确提示按原截止日重算，旧标题与定义仍取固定修订。

日报周报的“图表”节位于研判之后、策略之前，复用草稿 `sections.dashboard` 的显示开关与按语。清单依次纳入显示中的研判引用、策略卡片及交易计划引用、最多六条另选绑定指标；同图 ID 保留首次位置、取最大修订，图说汇总引用处与挂载依据/条件。另选指标与引用图唯一直接曲线重复时只显示引用图，草稿中的原手选与图说仍保留。引用图不受六条上限限制。

页面 `#report-figure-data` JSON 与报告 JSON 的 `report_figures` 提供完整清单：`key`、`kind`、`title`、`caption`、`unit`、`as_of`、`render_url`，引用图另含固定 `reference`、`references` 和 `single_series_id`，指标图另含 `series_id`。前端进入视口后串行请求 `GET /api/sn/reports/figures/{encodeURIComponent(key)}?date=YYYY-MM-DD&period=daily|weekly&revision=草稿版本`。服务端重新组装授权清单再校验 key；引用图返回 `{figure, rendered}`（`rendered` 复用图表引用读取结果，可直接传给 ChartKit），指标图返回 `{figure, series}`；单图不可读返回 `status: unavailable` 与 `notice`，保留标题和原因。定义固定在引用修订，数据截止报告日期，沿用图表库 ACL、来源核验及每批 256 指标/20000 点预算。Markdown 只列标题、图说、单位与截至日；冻结归档只列已保存引用，不读图表或观测，受限视角不纳入引用图。新版按本期报告内容生成 PPT 将复用此接口，生成器留待下一步实现。

## 九、研究维度

`/sn/dimensions` 在指标与研究判断之间提供研究台自己的维度看板，与产业图自由画布各自保存。未保存时采用共享契约 `research_dimensions.default_dimensions()` 的六维度（`price/supply/demand/inventory/balance/macro`）；显示名为价格与价差、供给、需求、库存、平衡、宏观。通用类别仍使用共享协议的 `CATEGORIES`，页面显示类别中文名。

配置存入 `SourceMapping` 的 `DIMENSIONS_KEY` 研究台作用域键，结构为 `{dimensions:[{id,label,category,description,sections:[{id,label,items:[{kind,id,revision?}]}]}]}`。最多12个维度、每维度8个环节、每环节12条、全台96条，`kind+id` 全台不能重复。新维度由服务端生成 `d-` 加8位小写十六进制编号，改名、排序保留编号；新环节可省略编号由服务端生成。图表必须指定有效修订号，读取固定修订定义，数据按所选截至日重算。已有失效绑定仍保留并返回原因；不能新绑失效条目。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/sn/dimensions` | 有序配置、条目名称/单位/频率/来源/工作表、失效原因、`revision`、`can_write`、类别显示名、依据统计 |
| PUT | `/api/sn/dimensions` | `{revision,dimensions,confirm_delete?:[维度id]}` 整份保存；初始revision为0，成功递增；修订冲突409；删除有引用维度且未确认返回409及`references:{id:条数}` |
| GET | `/api/sn/dimensions/data?date=YYYY-MM-DD&period=daily\|weekly` | 本期数据，省略date取已绑定指标与图表操作数中最新有效观测日；省略period为weekly |
| GET | `/api/sn/dimensions/templates` | 返回随代码发布的`templates:[{id,name,applicability,dimensions}]`，不写数据库 |
| POST | `/api/sn/dimensions/templates/{template_id}/draft` | `{revision,dimensions?:当前编辑草稿}`，合并模板结构与已有配置，返回配置描述、`template`、`warnings`；模板外维度带`template_extra:true`，不保存 |
| POST | `/api/sn/dimensions/suggestions` | `{model_id,dimensions?:当前编辑草稿,date?:YYYY-MM-DD}`，按草稿结构（省略时按已保存配置）逐环节生成检索说法、全目录排序召回、模型挑选；返回`items:[{series_id,dimension,section,reason,name,unit,frequency,...}]`及各环节候选数和留空原因，不保存 |
| GET | `/api/sn/dimensions/sources?search=&offset=0&limit=20` | 复用已授权原文选择路径，返回`items:[{title,citation}],next_offset` |
| POST | `/api/sn/dimensions/infer` | `{model_id,sources:[KnowledgeFileCitation]}`，选1–3份不同资料，返回带新编号的维度/空环节草稿，不保存 |

只有来源版本2的研究台开放完整接口，读取要求指标页面授权，保存与生成模板草稿要求共享写权限。模型建议同核心关注要求来源可读、账号可写、共享可编辑；模型分组采用本台维度结构，传入草稿时只提取名称、类别、说明和环节，草稿中的条目ID不成为候选证据，程序仅校验真实ID、合法维度、数量和格式。归纳沿用原文读取的版本、绑定、原件/解析正文验证，模型前后复核正文摘要与出处；共享正文读取器仍验证真实来源，维度入口独立校验指标页面与共享写权限。失败如实报错，不用固定列表补齐。

受限视角沿用核心关注规则：页面只读服务端已保存的指标绑定及最新两条必要观测（较上期），不接受自选日期/周期、不读目录/原文/任意历史、不开放修改接口。固定修订图表、同期排名与完整走势显示授权限制原因。来源可读但无共享编辑权限的普通查看成员可以读取完整看板。

本期指标数据包含`latest`、原始`unit`、真实观测`date`、`baseline:{date,value,label,target_date,kind}`、`change`、`change_pct`（比例，显示值乘100）、`direction`、`position`、`freshness`、最近26个有效观测`points`、`display`格式化文本及截断提示。计算只使用截至日（含）前真实有限有效观测，不填零、不插值、不换算单位：

- daily取上一条有效观测；weekly取“截至日前7天当日或之前”的最后有效观测，返回目标日与实际对比日。月度及更低频统一取上一条并标明“较上期”；只有频率未明确时，才以实际间隔至少28天识别低频，明确的日/周频保持原口径。缺少基准不输出变化，基准零不输出变化率；变化率为差值除以基准绝对值。
- 是否本期更新单独按报告窗口判断：daily基准日为截至日前1天，weekly为前7天，日、周、月及更低频均适用。最新有效观测日不晚于窗口基准日，或计算基准与最新为同一天时，`direction`返回新增值`no_update`，`update_status`为`no_update`，`update_notice`为“本期无新数据（最新 YYYY-MM-DD）”，`comparison_start_date`保留窗口基准日；有本期观测时`update_status`为`updated`。原`previous/baseline/change/change_pct/display`计算口径保留，尤其低频“较上期”差值仍可读取；展示本期方向时须先识别`no_update`，不把无更新的零变化写为持平；本期确有新观测且数值相同仍为`flat`。同期位置和过旧提示继续提供。
- 同期采用内置自然年模板，容差与覆盖率复用`compute/cycles.py`，统计最近最多5个有观测的往期自然年，返回从高到低的`rank/(n+1)`及`rank_low`。`n<3`或当前期覆盖不足时不给排名并说明原因，不把缺失期补为零。
- 过旧提示复用`strategy_monitor._staleness`，相对截至日计算。显示精度复用`number_format`，保留原始数值与单位。
- 指标与图表全部真实操作数按“指标ID、有效截至窗口”去重，20000点是每批上限，不再按全页指标数平分；每批不超过256指标且合计不超过20000点，单指标最多2000点。仅根据真实频率元数据估算五个完整往期自然年加当前年的读取窗口，按`ceil(6×366/频率间隔天数)+2`预留闰年与边界余量，并至少保留26点供走势使用：日度及未知频率2000点、周度316点、月度81点、季度27点、半年和年度26点。固定范围图表先把截至日限制到定义的结束日，图表操作数保留原2000点读取窗口；与指标共享操作数时采用较大窗口。批次之间沿用C1的同请求HTTP连接及已核验目录，不跨请求缓存结果。普通单项失败二分隔离，保留原位置并列入`failed`；权限或来源版本变化拒绝整个读取，不借部分结果绕过授权。
- 混合频率分组可复用同请求内已核验完整目录的子集：仅限同一授权作用域对象、显式指标ID、无搜索/来源筛选、从第0页开始且父目录完整无截断；子集保留父来源版本并重算条数与缺失ID。不同账号、授权、请求、分页或筛选均不据此复用；后续观测来源版本变化仍返回409，不能用新目录与旧元数据拼出部分结果。
- 原`limited`与`warnings`中的`history_limited`继续表示底层历史确有截断；新增卡片`history_coverage:{past_cycles:5,available_cycles:n,start_date,end_date,limited}`，其中`limited`仅在截断可能影响近5个往期同期时为真（样本不足且首条已读观测晚于最新观测年前5年的年初）。来源本身历史短不算预算不足，已有5个同期样本时也不提示读取覆盖不足。顶层`history_coverage_limited`汇总这一影响，原警告字段保留供已有消费者读取。`point_limit`保留每指标读取上界，卡片同名字段为实际频率窗口；`point_budget`仍为本请求全部去重窗口的点数预算总和，其值可超过20000，新增`batch_point_budget=20000`、`batch_series_limit=256`明确批次限制。
- 每维度`summary`包含`up/down/flat/no_update`和同期前两高/前两低的`extreme_high/extreme_low/extreme`，本期无新观测只计`no_update`，不计入涨、跌、持平；同一个指标即使同时属于高低极端也只计一次`extreme`。没有变化/排名的数据不计入相应数量。图表返回固定定义和复用ChartKit的`payload`。
- 指标卡片与配置条目优先采用目录可读`name`，其次`metric`，复用`research_display.indicator_name`清理展示文本。卡片正文只保留名称、最新值与已知单位、观测日、本期变化或“本期无新数据”、同期位置一句、过旧时“停更N天”小标记及走势线；单位为空或“未注明”时隐藏，无排名时同期位置显示“—”。工作表`sheet`、来源文件、频率、无更新完整说明及计算/覆盖提示归入右上角ⓘ，同类提示合并后每类只出现一次；支持悬停、键盘聚焦和点击固定查看。全局提示仅在确有覆盖影响或条目失败时合并为一条，已读窗口足够时不因更早历史截断提示不足。只改变展示，不改写目录、原始单位、指标绑定或已有计算字段。

50指标合成计时：使用2014–2024日度历史，截至2024-03-29的每个指标读取2000点（均超过5年且同期`n=5`），共5批、100000点；每请求5次目录读取、5次观测读取，仅创建并关闭1个HTTP Client，同组目录只读一次。`tests/test_dimension_data_performance.py`保留真实路由、签名、Client/TLS初始化、JSON核验与周期计算，仅以MockTransport模拟上游网络。本机无额外延迟三轮3.183/1.083/1.223秒（中位1.223秒）；每次上游调用增加5ms时3.288/1.128/1.158秒（中位1.158秒），最高3.288秒，合成场景满足单次≤8秒，保持一次请求返回；宿主负载与首轮初始化造成波动，不能将两组中位数差异解释为延迟收益。真实棉花页面及远端服务耗时未验收，不据此承诺生产耗时。

依据统计直接容忍读取`contradiction.bull/bear.evidence[].dimension`可选字段：有研判页面授权时，当前可见且属于本研究台的生效研判中bull为支持、bear为反对，无字段计`evidence.unassigned`，未知编号计`evidence.deleted`。各维度`references`含`support/oppose/total`。删除确认后不改写任何研判，原编号将计入已删除维度，留待研判重新指派。

“一页周报”可直接调用`GET /api/sn/dimensions/data?date=报告截至日&period=weekly`（日报用daily）。按响应`dimensions`数组顺序逐维度读取`id/label/category/description`、各`sections[].items[]`的真实本期数据及`summary`；使用`baseline.date`表述比较日期、`position.n`说明同期样本、`failed/status/reason/warnings`保留数据限制。新增`direction=no_update`时使用`update_notice`说明停更，不从`change=0`或仍保留的低频较上期差值推断本期方向；读取`summary.no_update`单列本期无新数据数。报告应传明确日期，避免默认最新日随来源更新改变；配置版本由顶层`revision`标识，此接口读取实时配置，不是冻结归档接口。

模型推荐以每个维度的每个环节为研究条目；无环节时以维度本身为条目，`section`返回空字符串。条目内容包含维度名、说明与环节名。模型先写检索说法，程序复用研判的`judgment_recall`通用函数和`CatalogRecall`对完整授权目录排序召回；每个条目都参与，不按工作表顺序截断。每环节候选数依`RECALL_STEPS`的20、12、8逐级退让以满足请求容量，仍超容量则报错。候选附截至`date`（省略时为当天）的最新有效观测日、频率、单位、工作表，由模型判断代表性、口径及长期停更风险。提示要求每环节选择最有代表性的1–4个，同品种多个合约月份仅在含义不同的情况下分别选择，缺少合适指标时留空并说明；程序不按名称、关键词或日期替模型筛选、补选。

程序校验维度、环节存在，指标属于本环节本次展示候选，每环节至多4个、总计至多96个；超限或模型格式无效直接422，调用失败如实返回，不回退固定列表。调用审计使用`dimension_queries`、`dimension_fields`。推荐响应新增`as_of`、`recall_per_section`和`sections:[{dimension,section,item_id,section_id,candidate_count,selected_count,empty_reason}]`；旧`items`结构继续可读，并附`latest_date/item_id/section_id`。`item_id`为本次请求按维度与环节顺序生成的临时条目编号，`section_id`为草稿已有环节编号（没有时为空），用于区分同维度同名环节；模型同名选择必须指明`item_id`，页面采用时保留原环节归属。`field_count`为完整目录条数，`selected_field_count`为本次展示候选的去重条数，`truncated=false`表示未使用工作表字段截断；`recall_per_section`记录本次采用的候选数上限。留空原因来自模型，不由程序以业务规则填造。研究员仍需采用到编辑草稿并保存。

### 内置维度模板库与从模板开始

模板定义在 `commodity-research/src/tin/web/dimension_templates.py` 的 `TEMPLATE_DATA`，随代码发布，不写数据库，只提供维度名称、通用类别、一句说明和环节名，不包含指标或图表绑定。首批提供“通用六维度”和适用于棉花、棉纱、纺织相关品种的“纺织产业链”。前者复用 `default_dimensions()`，新建维度使用六个固定编号，环节为空；合并时仍优先保留同名已有维度编号以兼容引用。后者整理真实棉花周报的价格与价差、美棉供给、国内供给与进口、纺纱需求、织布与终端需求、库存与仓单、替代品、资金与宏观结构。模板加载时统一调用 `research_dimensions.validate_dimension_list` 校验。

未保存过配置的页面提供“用通用六维度开始 / 选择行业模板 / 从往期周报归纳”三个入口；编辑工具栏也可以套用模板。套用只生成可编辑草稿，不写配置，研究员仍需点击“保存”。套用后可一键让模型按草稿维度推荐真实指标，再由研究员选择确认；模板和环节名不得用于关键词匹配或自动分配指标。

已有配置按维度编号优先、同名维度其次对应，保留对应维度的已有编号、环节和条目，新增模板环节以空条目加入。无法对应的已有维度追加到草稿末尾并标为“模板外”，由研究员决定保留或删除；删除被研判引用的维度继续使用原有显式确认流程，不改写研判依据。未保存过配置时，隐式默认六维度不作为已有自定义配置追加。合并后暂时超过12个维度或每维度8个环节时仍保留完整草稿并提示，研究员删减到配置上限后才能保存，不静默丢弃原条目。

### 如何新增一个模板

1. 从真实研究报告提炼稳定的研究结构，记录模板名称、适用品种说明、各维度关注内容和环节名；说明只写“看什么”，不写市场结论。
2. 在内置模板数据文件中增加结构；每个维度归入 `research_dimensions.CATEGORIES` 中的通用类别。同一类别可以有多个细分维度，不另造通用类别。
3. 只写结构，不写指标 ID、图表 ID、取数规则或自动归类关键词。行业模板的维度和环节编号在套用时由服务端生成；默认六维度继续复用固定编号。
4. 运行模板数据校验、草稿合并与权限测试，再运行 `test_dimension_*.py` 和 `dimensions-ui.cjs`。核对空配置、已有配置、模板外维度、引用删除确认以及未保存草稿的模型建议流程。

## 从往期周报导入常用图

入口位于 `/sn/charts/import`“从原表导入图表”页面现有结果区之后，展开“从往期周报导入常用图”。原表 Excel 原生图的工作表预览与确认流程保持独立；新入口只复用现有选择器、图表库卡片与 ChartKit，不添加全局样式或调整其他页面版式。

### 来源与可读证据

沿用 `strategy_citations._file_options` 的已授权文件选择，限 PPTX、PDF。识别需要来源版本2、指标页面授权、来源可读、账号可写及研究台共享编辑权限；受限视角不开放。文件选择携带真实 `source_binding_id / knowledge_id / file_version`，服务端再次检查绑定、知识库归属、文件版本和解析完成状态。只读取知识库已有的文本解析片段，不下载或重新解析原件。

2026-11-17 对开发库的只读结构抽查：16份 PPTX 有8051条文本片段，长度16–6764字符，其中472条含 `<!-- Slide number: N -->`，2463条含原图文字标记，3035条含 Markdown 图片标记，630条的页定位字段非NULL；另有2份 PDF、60条文本片段。该统计仅说明当时已有解析形态，不保证每份报告都有图例。解析实现可能提供页标题、正文、备注、图片链接/说明，以及 EMF 缓存文本中的图标题、图例与坐标刻度；定位采用 `source_locators` 的 `slide/page` 或解析器明确页码标记。图片链接本身不能证明图例可读，缓存刻度与旧数值不作为观测数据。无可靠页定位时展示“片段N”，不推测页码。

片段读取复用 `_parsed_chunk_rows(..., structure_digest=True)` 的租户、文件归属、递增顺序、分页完整性、状态、修订号检查，上限2000片段、200万字符。不使用维度归纳的截短摘要：完整片段按顺序分批，每批最多12个页/顺序位置、24个片段、24000字符，最多识别48张图；超长单片段按位置拆分，模型提示仍受现有字节容量限制。初次读取前后、每批模型完成后、全部完成后及预览/导入时，复核文件元数据版本、完整片段内容摘要、修订号、顺序和页定位摘要；变化返回409，不混用新旧证据。

### 识别、召回与生成

每批由模型识别证据上的图，返回原文图标题、原文图例、明确写出的单位、页码和逐字依据。图例、单位及引用必须在本批真实片段的逐字依据中；依据的 `chunk_id` 与 `quote` 不属于本批时仍拒绝。标题缺失或无效时，依次使用模型给出的 `title_candidates`、已核验系列名或短依据作为候选，且必须是已核验依据片段中的原文子串、长度符合标题限制；回退会提示研究员核对。页码只用于展示，统一取最早依据片段的实际位置；与模型页码不一致时记录提示，无可靠页码则显示片段顺序，不因此丢图。非法图型、编造系列或缺少依据的图降级为失败项，保留原因；同批内缺失映射协议或非法候选也逐图降级，保留其他图，模型调用整体失败则按批隔离。

图型由模型理解语义后选择 `trend`（走势）、`seasonal`（按年份分列的同期对比）、`comparison`（多指标对比），并必须显式输出 `legend_semantics`：`indicators` 为不同业务指标，`periods` 为同指标的不同年份/年度等周期。周期图由模型先按指标语义归组，`series.name` 是共同指标的原文短语，`series.legends` 保留全部原文周期图例；普通单指标同期图只召回、映射一次，真正多指标同期图保留多个指标组。程序只校验协议值与原文，不用年份正则或名称相似度推断图例语义；缺少语义字段会逐图失败。页码标记正则仅解析解析器的位置协议。

每个指标组先由模型写1–3个检索说法，再复用 `judgment_recall` 与 `CatalogRecall` 对完整授权指标目录召回，按20/12/8候选容量退让；模型结合标题、图例、单位、工作表和来源口径选择首选或明确留空。挑选提示明确要求核对对象、统计口径、地域、单位和频率，候选非空也可以全部不选，无法确认口径一致时鼓励返回 `null` 并说明原因。程序与确认页面都只接受该指标组本次展示过的候选 ID，不能把其他图例候选或客户端自报 ID 当作授权。候选可手动改选，不按相似名称自动绑定。未选系列保留在确认页，提示“指标库中未找到，请手动选择或跳过”，整图默认不勾选，不冒充定义失败。

确认草稿复用 `ChartDefinition` 与 `validate_definition`：标题保留原文，说明 `note` 固定为空，分组默认周报文件名（至多80字符，可改）；原文结论、旧数值及模型口径理由不写入图表说明或研究正文。走势和多指标对比用 `recent`、最近120点、原值；同期图按所选真实指标形成周期曲线，原图图例保留在结构来源记录中。任何图型的多个系列映射到同一真实指标时，在逐系列校验候选权限后按 ID 去重，并在确认与预览中提示；不同指标仍保留多条。真实目录单位决定左右轴，同单位同轴、最多两种单位；不使用模型单位覆盖目录，不换算单位、不填零、不插值。

现有内置模板只有“自然年”和“春节前后8周”。日、周、月、季、年及未知频率的按年份同期图均可使用“自然年”，保留各自真实日期与实际观测频率；频率无法证明春节事件语义，因此不会凭频率选择春节模板。当前不自动复刻报告里的非自然年或事件对齐方式，可在导入后用现有图表编辑器调整。同期曲线数仍受现有图表定义上限限制，超限会列出具体校验原因。

### 确认、进度与写入

`/api/sn/charts/import/report` 提供 `GET /files`、`POST /recognize`、`GET /jobs/{id}`、`POST /preview` 和 `POST /apply`。识别返回后台任务编号，页面轮询批次进度；每任务默认3路有限并发，可用 `TIN_REPORT_CHART_IMPORT_CONCURRENCY` 配置为1–8，1即串行。各批仍经过原有提取、检索说法、指标选择三阶段模型调用与 `llm_calls` 审计，调用失败和取消也留痕。每批最多360秒，识别总预算1800秒，总超时后另留最多120秒复核已完成部分。完成进度计数包含成功或失败的已处理批次，不依赖完成先后；结果按原批次顺序汇总，单批模型失败或超时列出原因并继续其他批次，权限或版本变化中止并回收其余任务。验源、定义准备和进度保存串行发布，避免并发覆盖进度。任务草稿存于原有研究台隔离存储，按租户、研究台、用户和来源授权指纹校验，仅原发起者可核对；1小时过期，下次提交清理过期草稿。进程重启不自动恢复正在识别的任务，超时后提示重新识别。

确认页按真实页码或依据片段位置分组，每组展示图表候选及对应失败项，便于逐页核对。每张卡片展示原文图标题、指标组及原始图例、真实指标候选、可改图型及 ChartKit 的真实数据小预览，页码修正、标题回退与重复映射提示单独展示。“可能重复”“未找到指标”“定义失败”分别标识并默认不勾选；缺指标不发起无效数据预览，补全后可预览。预览失败的卡片不能勾选；修改映射或图型会重新预览，问题卡修复或重试成功后仍须研究员手动勾选。已有图表的真实指标集合与图型相同则提示“可能重复”，研究员仍可明确选中。该提示区分周期图与走势/多指标图，后者不因recent/since/range时间窗口不同而漏报；不以图标题匹配，也不作为去重删除规则。
