# 从知识库建立研究工作台

新建工作台选择绑定知识库、名称和起步模板，随后在工作台内完成资料准备。模板只决定起步说明和证据要求，不携带业务指标、原工作台成果、文件匹配规则或示例答案。所有模板复用原研究工作台的页面、导航、产业图编辑器和元素间距；新建工作台使用独立研究范围，不读取原研究数据库补齐内容。2026-10-15 修订已撤去第一版独立工作台的重排界面。

## 创建与首次引导

知识库的“创建工作台”入口预填当前知识库。还没有知识库时，可在创建表单旁使用原生新建入口。表单采用现有主题、紧凑单行输入、四行模板选项和小尺寸按钮；不要求先填写研究目标长文本。

| 起步模板 | 起步侧重点（主研究页面保持一致） |
| --- | --- |
| 产业研究 | 指标与图表、研究结构、研究判断、跟踪事项、简报、策略、导出 |
| 数据跟踪 | 指标、趋势、对比、更新状态、导出 |
| 专题研究 | 资料、笔记、证据、问答、简报 |
| 空白工作台 | 来源与问答，可按需添加功能 |

模板不会裁剪或重排原生主研究页面。“跟踪事项”和“更新状态”目前提供已登记资料的状态入口；尚未配置的监测规则、外部采集器和实时信号会显示缺口，不自动开启。

第一次创建时显示简短说明。进入后，“导入资料、核对来源、开始研究”三项引导位于可收起的小浮层，可以跳过和重新打开；个人引导状态与真实数据准备状态分开保存，点击完成不会制造可用指标。资料准备在主研究区内的抽屉完成，原研究导航、首页、产业图、指标、判断、策略和报告沿用同一套原生模板。问答助手由按钮唤起并在右侧保留，直到用户收起；打开资料抽屉不会遮住助手。点击管理卡片或左侧工作台名称直接进入，旧预览地址重定向至工作台。

新建工作台的主知识库绑定固定。同一知识库允许建立多个工作台，指标和观测统一读取该库当前已确认的结构化数据；研究图谱、个人判断、成果和聊天范围按工作台保存。共享知识库继续按其真实所属空间和当前授权验证。

## 导入、核对与研究

1. 在工作台内上传文件或整个文件夹，沿用知识库原生上传与目录层级，逐文件显示成功和失败。非表格文档沿用知识库解析；Excel 保存原件后显式核对。图片与 ZIP 可以只保存原件，避免自动图像识别；ZIP 不自动解压或重复索引。
2. Excel 原件旁的“结构化解析”直接进入绑定知识库的 Excel 导入页，并定位真实原件 ID；资料抽屉不再提供第二套指标导入与确认流程。
3. 在知识库统一核对原表头、日期列、数据范围、字段名、单位与频率。自动识别完成不代表已确认，只有显式确认的工作表进入研究指标。用途、业务口径和映射仍由用户或模型结合真实证据决定。
4. 研究台直接读取当前已确认字段与观测，不再次复制、换算或补齐。日期、单位、频率和原单元格保留来源证据；日期标签不声明发布时间或当时可知性，缺失和错误不填零。
5. 原生产业图从空节点、空连线开始，绑定知识库真实字段的稳定 ID；不会复制现有锡台图谱。知识库更新后直接读取当前版本；撤回确认或删除原件后旧绑定显示缺失，不借用历史数值。原台图谱布局保留，历史独立序列不按名称自动猜配到新字段，用户需选择真实知识库字段重新绑定。
6. 用户可以建立研究结构、判断、笔记、简报和策略草稿。确认成果必须显式确认并关联真实来源；草稿不代表已发布简报、已执行策略或真实成交。个人成果按账号隔离，研究结构在本台按权限共享。

原件中的关系、方法或图示可以作为本次人工研究依据；系统不自动假定它们已经被采纳。文件没有提供的实时行情、个人历史判断和交易过程保持空白。当前实现没有自动提取整套产业图谱、注册外部采集器或自动生成简报/策略的编排。策略草稿沿用原有 SN 领域协议，尚未扩展成任意商品的交易规则；新独立台暂不开放自动生成策略按钮。原先依赖空间级任务的采集、终端导入入口会引导至本台资料准备，不能通过这些入口写入原工作台。

## 证据与恢复

字段导入冻结实际快照和原件哈希。重复确认相同请求幂等；更改已确认的单位、口径、频率或登记时刻须明确处理，不能静默忽略。研究台没有第二份可写指标事实：每次读取重新核验原件、确认状态和版本；上游不可用时返回错误，不显示旧副本。旧独立研究事实保留在原 SQLite 作为回滚备份，运行时不可读取。

保存人工研究记录时，对实际引用的文件核验大小、哈希和下载权限，留存不可变原件。修改记录保留真实修订版本，并用版本号阻止并发覆盖。网页或在线编辑内容没有可捕获原件时，明确标为“仅元数据”；旧记录没有保存过的历史不补造。

冻结原件下载仍须具备可见研究引用、当前知识库授权及原生原件下载权限。原件之后更新，只检查当前访问权限，返回的仍是研究当时冻结的字节；权限撤销后拒绝下载。

## 问答边界

聊天会话由服务端固定工作台身份，每轮重新核验工作台、知识库，以及明确指定文件的所属范围；读取具体原件时再核验原生文件权限。分叉继承范围，改标题不能移除或换绑；工作台研究工具读绑定知识库当前已确认数据与本台当前账号成果，不回退到空间旧成果。原生文档和结构化读取仅限绑定知识库。删除来源不会抹除已保留的研究记录，但不能继续下载失去授权的原件。

问答侧栏复用主问答助手输入框，模型和 @知识库/文件在输入框内选择；模型与来源选择保留本台局部状态，不覆盖主问答设置。本台聊天不进入空间通用的跨会话记忆或历史向量索引；外部助手、网页浏览、MCP 和技能不能通过本台会话绕过范围。业务意图与取数计划仍由模型根据问题、上下文和真实证据决定，程序只执行权限、真实 ID、参数及计算校验。本文不表示遗留问答整条链路已完成硬编码审计，另见 `QUESTION_HARDCODING_AUDIT.md`。

模型推理需要实际可用的免费模型与额度。没有确认供应商剩余额度时，不以模型名称含 Flash 为依据发起调用；手动导入、核对、图表和草稿仍可使用。

## 部署与迁移

- Go 元数据新增 SQLite 版本 41、PostgreSQL 版本 123，保存模板版本、研究范围、个人引导及会话绑定。旧工作台默认 `legacy`，新创建为 `isolated`。
- 研究服务新增 `9f17b80c4a32` 和 `a618c3e72f45` 两个 Alembic 版本，分别保存工作台研究记录，以及真实来源快照与修订历史。新增 `e76b9a310d22` 移除成果引用指向旧本地指标表的外键，保留判断外键与应用层真实字段验证；旧迁移不改写。
- 平台元数据、结构化知识库和研究成果仍使用各自的存储。唯一事实源是知识库当前已确认结构化快照，研究库只维护成果；原 UI 的 SQL 查询通过请求内只读内存投影兼容，连接关闭即销毁，不落盘复制事实。
- `legacy` 与 `isolated` 均必须绑定知识库读取事实。该标记只决定成果保存位置，旧台继续保留原成果数据库。作用域标记校验主知识库及所属空间，拒绝复用不一致范围。
- 当前完整读取上限为每库 128 份原件、200 万条观测，超限明确拒绝，不提供截断或旧副本；暂无跨请求事实缓存。
- 原空间自动宏观采集尚未登记为 Default 知识库来源，旧未绑定入口返回明确错误；不会用旧独立指标填补 Default。后续需在知识库统一登记采集源。
- 前端、Go、结构化服务和研究服务需一起更新。只更新前端不能提供新的隔离与证据 API。

验证结果与桌面文件夹冷启动记录另见本次验收记录；测试数据和原件不进入生产源码。
