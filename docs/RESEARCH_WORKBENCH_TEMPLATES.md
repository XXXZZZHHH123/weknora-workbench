# 从知识库建立研究工作台

新建工作台选择绑定知识库、名称和起步模板，随后在工作台内完成资料准备。模板只决定功能入口和证据要求，不携带业务指标、原工作台成果、文件匹配规则或示例答案。原有工作台保留原来的研究模式；新建工作台使用独立研究范围，不读取原研究数据库补齐内容。

## 创建与首次引导

知识库的“创建工作台”入口预填当前知识库。还没有知识库时，可在创建表单旁使用原生新建入口。表单采用现有主题、紧凑单行输入、四行模板选项和小尺寸按钮；不要求先填写研究目标长文本。

| 起步模板 | 初始功能 |
| --- | --- |
| 产业研究 | 指标与图表、研究结构、研究判断、跟踪事项、简报、策略、导出 |
| 数据跟踪 | 指标、趋势、对比、更新状态、导出 |
| 专题研究 | 资料、笔记、证据、问答、简报 |
| 空白工作台 | 来源与问答，可按需添加功能 |

“跟踪事项”和“更新状态”目前提供已登记资料的状态入口；尚未配置的监测规则、外部采集器和实时信号会显示缺口，不自动开启。

第一次创建时显示简短说明。进入后，“导入资料、核对来源、开始研究”三项引导可以展开、收起、跳过和重新打开；个人引导状态与真实数据准备状态分开保存，点击完成不会制造可用指标。功能采用左侧目录，问答助手由按钮唤起并在右侧保留，直到用户收起。

新建工作台的主知识库绑定固定。同一知识库允许建立多个工作台，各台的指标、观测、研究记录与聊天范围彼此独立。共享知识库继续按其真实所属空间和当前授权验证。

## 导入、核对与研究

1. 在工作台内上传文件或整个文件夹，沿用知识库原生上传与目录层级，逐文件显示成功和失败。非表格文档沿用知识库解析；Excel 保存原件后显式核对。图片与 ZIP 可以只保存原件，避免自动图像识别；ZIP 不自动解压或重复索引。
2. 为来源明确选择用途：数值观测、取数清单、研究方法或规格说明。清单和方法文档不会作为数值观测写入。
3. 新工作台从实际原件扫描候选工作表，不恢复历史工作表映射、固定品种配置或原工作台结果。紧凑核对区提供原表头样本、日期列、数据起止行、字段名、单位与频率；编辑后必须重新预览。
4. 登记实际字段时核对单位、口径和时间含义。不会猜测原件缺失单位，也不会默认进行单位换算。日期超出当前日期的有效数值须额外确认；缺失、错误、无缓存公式不会填零。“原表日期”表示原件日期或统计期标签，不声称它是发布时间或当时可知时点。
5. 图表使用本工作台实际登记序列。趋势和对比保留单位、时间和来源，可回到冻结版本与原单元格。字段分页、研究记录分页和导出均处理后续页面，避免只展示或导出前一百条。
6. 用户可以建立研究结构、判断、笔记、简报和策略草稿。确认成果必须显式确认并关联真实来源；草稿不代表已发布简报、已执行策略或真实成交。个人成果按账号隔离，研究结构在本台按权限共享。

原件中的关系、方法或图示可以作为本次人工研究依据；系统不自动假定它们已经被采纳。文件没有提供的实时行情、个人历史判断和交易过程保持空白。当前实现没有自动提取整套产业图谱、注册外部采集器或自动生成简报/策略的编排。

## 证据与恢复

字段导入冻结实际快照和原件哈希。重复确认相同请求幂等；更改已确认的单位、口径、频率或登记时刻须明确处理，不能静默忽略。更新后的数据集不会自动覆盖旧研究事实。

保存人工研究记录时，对实际引用的文件核验大小、哈希和下载权限，留存不可变原件。修改记录保留真实修订版本，并用版本号阻止并发覆盖。网页或在线编辑内容没有可捕获原件时，明确标为“仅元数据”；旧记录没有保存过的历史不补造。

冻结原件下载仍须具备可见研究引用、当前知识库授权及原生原件下载权限。原件之后更新，只检查当前访问权限，返回的仍是研究当时冻结的字节；权限撤销后拒绝下载。

## 问答边界

聊天会话由服务端固定工作台身份，每轮重新核验工作台、知识库，以及明确指定文件的所属范围；读取具体原件时再核验原生文件权限。分叉继承范围，改标题不能移除或换绑；工作台研究工具读该台已登记数据与当前账号成果，不回退到空间旧成果。原生文档和结构化读取仅限绑定知识库。删除来源不会抹除已保留的研究记录，但不能继续下载失去授权的原件。

本台聊天不进入空间通用的跨会话记忆或历史向量索引；外部助手、网页浏览、MCP 和技能不能通过本台会话绕过范围。业务意图与取数计划仍由模型根据问题、上下文和真实证据决定，程序只执行权限、真实 ID、参数及计算校验。本文不表示遗留问答整条链路已完成硬编码审计，另见 `QUESTION_HARDCODING_AUDIT.md`。

模型推理需要实际可用的免费模型与额度。没有确认供应商剩余额度时，不以模型名称含 Flash 为依据发起调用；手动导入、核对、图表和草稿仍可使用。

## 部署与迁移

- Go 元数据新增 SQLite 版本 41、PostgreSQL 版本 123，保存模板版本、研究范围、个人引导及会话绑定。旧工作台默认 `legacy`，新创建为 `isolated`。
- 研究服务新增 `9f17b80c4a32` 和 `a618c3e72f45` 两个 Alembic 版本，分别保存工作台研究记录，以及真实来源快照与修订历史。已应用的迁移不改写。
- 新工作台研究数据存入按实际空间与工作台分开的数据库；作用域标记校验主知识库及所属空间，拒绝复用不一致范围。
- 前端、Go、结构化服务和研究服务需一起更新。只更新前端不能提供新的隔离与证据 API。

验证结果与桌面文件夹冷启动记录另见本次验收记录；测试数据和原件不进入生产源码。
