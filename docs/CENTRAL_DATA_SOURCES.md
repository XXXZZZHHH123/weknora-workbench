# 中心来源与研究工作台

研究工作台独立保存研究成果，通过来源关系读取中心数据集和用户知识库。来源关联不复制观测数据；删除知识库会解除来源，使相应指标不可用，保留工作台、布局、判断版本及其他来源。

## 存储关系

| 对象 | 存储 | 用途 |
| --- | --- | --- |
| 用户知识库 | 现有知识库、原件及已确认结构化快照 | 保存用户资料及字段口径 |
| 中心数据集 | `central_datasets` | 登记中心来源；第一阶段原地复用各空间已有 Default |
| 工作台来源 | `research_workbench_source_bindings` | 关联知识库或中心数据集，记录启用状态、授权及变更 |
| 工作台成果 | 现有工作台成果数据库 | 保存布局、核心指标配置、判断、策略、日报及版本 |

`knowledge_bases.system_role=central` 标记受保护的中心来源。普通成员不能编辑或删除它；已有读取权限的空间管理员可维护。保留现有读取授权，不把原本私有资料自动公开。

旧工作台的知识库及 Default 关系会迁为显式来源关联。保留知识库、文件、字段及已发布指标的真实 ID，不重写历史观测。兼容字段 `knowledge_base_id` 只表示首选用户知识库，不再决定工作台成果身份。工作台允许暂不关联来源。

## 加载预算

- 最多同时关联 8 个来源；历史移除记录不占预算，也不出现在当前来源清单中。
- 打开页面先读本台保存的绑定，再取必要数值，不装载全库观测。
- 指标目录每页最多 200 项，搜索在完整授权目录上执行。目录不读取观测或原始图表 XML。
- 普通取值每批最多 256 个真实指标 ID；历史或对比请求有独立点数预算。合约曲线在服务端统一选择真实共同日期。
- 元数据索引及原件哈希缓存按本地文件身份和快照版本失效；权限每次重新核验，不缓存授权。
- 模型分析只读取明确授权的指标元数据及用户提供的资料。目录超过分析容量时明确拒绝，不静默截断、补造口径或使用旧事实替代。

## 权限边界

工作台权限与来源权限分开。所有来源可直接访问时使用完整研究视角；有不可直接访问的来源时，按工作台主人配置及对应来源批准的页面展示受限视角。可读中心库不能提升私有知识库的权限。

每个来源分别请求、批准和撤销展示授权。未经请求的私有工作台名称不出现在来源主人的审批清单中。受限视角不能浏览全库目录、任意查询、下载原件或运行生成模型；只取获授权页面已绑定的必要数值。

`sources_revision` 用于检查来源变更。保存配置、模型预览和正式写入会核对当前来源与版本。移除或删除来源不复活旧绑定，不回读旧研究库事实；页面保留相应的缺失状态。

内部原件清单仅用于事实服务的真实性检查，不作为浏览器可获取的目录。内部请求需要服务证明；普通请求只能取得工作台来源摘要。

## 模型导入

研究逻辑先生成预览，再由用户显式保存为草稿。真实 ID、单位、逐字引用、阈值数字及版本仍按严格规则验证。模型可依据字段错误修正一次；仍无依据的量化条目完整列入待确认，不参与执行。有效规则与原文保留，草稿不会自动激活。

策略生成使用平台已配置的通用模型。期货报价通过用户保存的合约绑定定位真实知识库指标，不根据指标名称或旧研究库编号推断合约；缺少生效判断、报价或单位时说明缺口。

## 兼容与部署

SQLite 对应迁移 48，PostgreSQL 对应迁移 130。部署前备份主数据库及研究成果数据库；结构化原件和快照继续保留。前端、原生研究页面、Go 后端与结构化服务需要配套发布，避免新旧来源协议混用。

回滚不能仅把新工作台强制还原为单知识库。先保留来源关系和成果，确认目标版本支持当前协议，再执行回滚。
