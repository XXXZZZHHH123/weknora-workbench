## 两套事实的根因与处理

实际旧锡研究 SQLite 有 87 个指标、8009 条观测，绑定锡知识库尚无结构化数据集。此前 `legacy` 直接读取旧空间数据库，新台又可把结构化数据二次复制到研究库；两条入口都与知识库脱节。

现在平台元数据、原件/结构化数据、研究成果仍有各自的物理存储；唯一可用的研究事实源是绑定知识库当前显式确认的结构化快照。研究库不再接受指标与观测写入。原 UI 的 SQL 读取使用请求内只读内存投影，关闭连接即销毁；权限、当前原件 ID/哈希、确认状态与分页版本重新核验。上游失败、删除来源、撤回确认或版本变化，不回退到旧副本。

旧物理事实和研究成果保留为回滚与历史档案，实际旧台已显示零指标、零观测，原研究页面正常打开。旧图谱布局保留；原独立序列不按名称猜配到知识库字段，需在知识库确认后选择真实字段重新绑定。

知识库原件桥接显式 `restore_reviewed_state:false`，避免新流程恢复原空间映射。已存在于当前库、真实绑定且显式确认的数据仍能作为当前事实，不以历史扫描开关排除其合法性。Excel 默认关闭的向量检索开关不表示结构化数据失权。
