# 问答来源核验与耗时回归记录

本记录对应 2026-10-15 的服务器问题。业务验收数据仅保存在隔离的测试夹具和本机 `.build/qa-latency/`，不向业务知识库上传样例或固定答案。

## 已确认的原因

服务器当时运行的应用为 `74b2458`，并未部署后续文档能力更新，因此不能将这次故障归因于新文档沙箱。

- 美国各州面积题总耗时约 110.5 秒：20 轮主模型约 49.4 秒，工具约 14.4 秒，轮次耗尽后的终止合成约 46.5 秒。它已读到报告，但继续查找未导入的 Excel 数据。
- 价格种类的旧会话耗时约 129.9 秒，其中模型轮次约 128.3 秒，工具总计约 1.3 秒。重复复核与思考没有持续增加证据。
- 新会话同题约 146.5 秒，包含额外查询与一次字段模型超时。请求初始化仅几十毫秒，目录发现约一秒，主要瓶颈不是请求排队。
- 文档工具向模型展示图片 OCR 和图注，而数值核验只读取片段正文；混合表格/文档回答因此漏失合法数值依据。
- 部分拒绝也是正确的：旧草稿把部分匹配目录的实际数量写成另一个总数，不能为通过验收而放开。

## 通用修复

1. 实际引用片段中的已读取图片 OCR/图注参与数值核验。没有引用的图片、失败工具、网址数字、文档嵌入的伪工具 JSON 不成为计算依据。
2. 待澄清结果只登记真实完整字段身份，不将尚未放行的数据变成统计结果。
3. 独立复核保留每个工具的有界结构化视图、身份、来源覆盖和明确的遗漏标记，避免整条大结果被静默丢弃；程序校验仍使用完整运行结果。
4. 实际读到文档正文也触发来源复核；不要求将报告已有的原文数值强行改查 Excel。模型理解表头、基期、舍入和口径，程序执行新增计算。
5. 复核结果使用明确的最终答复字段，先解 JSON，再还原引用和资源。草稿不当作交付正文；最终完整性、数值及来源检查继续执行。
6. 数字疑点在首次独立复核前提供，避免先盲审再开启修复；被复核替换的首稿不额外调用一次完整性模型，最终候选仍检查。
7. 只有明确的只读工具操作可以并行；绑定来源、字段确认、写入和未知工具保留执行屏障。
8. 字段目录提供按真实工作表与原指标名的分组计数，覆盖分页前匹配集合，并标明候选范围。程序不替模型判断哪些指标属于用户所问业务类别。
9. 断流恢复只有已完成工具记录时显示处理中，避免退回“请求已发出”。

## 验证边界

回归同时检查速度和原始来源。第一轮面积题虽缩短至 18 秒，但误解了比例基准、输出草稿，判为未通过；不得以耗时下降替代正确性。原 PPT 表图与地图、Excel 表头已分别独立核对。原件、现有快照与历史均保留，服务器未部署新代码，也未修改业务数据。

这是一组来源链路和性能修复，不代表未审查代码或任意问题已完全正确。硬编码约束和后续审计仍见 `QUESTION_HARDCODING_AUDIT.md`。

文档新增计算使用 `calculate_source_values`：模型提交公式与来源计划，程序只接受本轮已授权实际读取的片段、逐字原文、完整数值及显式单位，以有理数执行批量四则运算。未知来源、拼接数字、无单位百分比、单位不一致、除零、函数/代码、超限输入均拒绝。它不访问任意数据库、不执行模型代码，也不推断业务含义；原文中的数据、模型的业务计划与确定性计算保持分离。

## 模型服务商配置

服务器故障记录实际调用 `qwen3.8-flash`，模型服务商被保存为 `generic`，端点实际为阿里云百炼。该配置会按通用接口发送思考控制格式，无法可靠表达百炼的 `enable_thinking`。已通过管理 API 备份并将该模型的服务商修正为 `aliyun`，名称、端点和凭据绑定保留；这不是代码部署。百炼的关闭思考与结构化输出要求见[官方说明](https://help.aliyun.com/zh/model-studio/deep-thinking)。本地先前同 ID 对应另一个模型别名，前几轮本地结果只作诊断，不用来声称同模型性能提升；最终验收使用服务器实际的 Qwen 模型名。

## 文档表格批量计算与交付边界

新增 `calculate_document_table`：模型根据真实已读分块选择表、行、列、单位和公式，程序从实际 Markdown/OCR 单元格批量计算，保留原始行、字段索引和精确结果。表格语法识别不判断商品、指标或业务意图。空值、不合法数值、零分母和解析停止明确报告，不补零；未知单位不能生成百分比。批量计算省去逐行重抄原值和引用的大参数；零散原文仍可使用来源绑定的四则工具。

两种计算协议均区分未知单位、有量纲、无量纲和已显示百分数；来源引用、行编号与任意元数据不作为额外计算结果。格式层只处理明确的答案响应契约：先解析答案对象，再还原来源和资源。终止合成使用同一契约，无效或不完整的对象不能作为已完成答复显示。
