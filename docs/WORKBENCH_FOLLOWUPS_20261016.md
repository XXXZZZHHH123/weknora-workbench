# 产业图、日报、全局查询与默认宏观来源修复

本轮接续 `2200589`，沿用原研究台、知识库与结构化页面主题。原始字段、来源与权限检查保持有效，没有新增业务问题关键词分支，也不宣称历史问答硬编码审计已全部处理。

## 产业图与 md管理

图片生成原先在调用模型前被拒绝：旧远程模型以 generic 供应商保存，而能力目录按实际供应商登记；Python 又把准确错误统一替换成能力、额度、资料或权限的泛化提示。

现在只对旧 generic 配置，从与真实动态供应商聊天 endpoint 精确匹配的目录补充输入能力。显式输入限制优先；未知模型、伪造域名、HTTP、不同端口和不同协议根路径均不放行。能力识别不会改变实际供应商、密钥、传输协议或模型配置。目录与生成入口一致，业务判断仍由所选模型依据完整资料和真实字段目录完成。

产业图仅保留一个“md管理”入口；资料生成、Markdown 编辑、导入和导出位于同一抽屉。生成结果是待确认草稿，不会自动覆盖已保存布局；切换资料、关闭抽屉或人工修改期间到达的旧结果不会覆盖当前内容。应用前仍核验真实绑定字段和来源版本。

真实云模型调用受用户的免费额度约束；本地模拟模型测试不作为真实模型质量验收。真实调用、模型与额度证据单独记录，不把缺少账户余额接口说成额度已核验。

## 日报记录与可读展示

“日报”页原先是快照 JSON 预览，包含所选日期及之前的各指标最新值、单位、数据时点、来源口径、派生计算及输入、当前研究判断、已登记信号和数据缺口；调查记录当前为空。它不是自动撰写的研究文章，未填写判断时不补造结论。

集成知识库模式依据当前已确认数据实时回放，原表或当前判断修订后回放可能变化；它并不是在该历史日期冻结的档案。独立模式实际存在的归档文件才读取生成时保存的记录。页面现在明确区分二者，展示可读指标表、判断、计算、信号与缺口，原始 JSON 保留在折叠详情和下载入口。

## 全部文件查询

数据查询默认“全部”，搜索当前已授权知识库中各业务文件的最新导入版本。历史版本和验收样例不进入全局目录；用户仍可选择单个文件。知识库导入按已验证的真实原件身份识别版本，独立同名文件不会互相排除；旧空间未绑定原件的数据保留既有版本行为。候选、图表及每条曲线保留真实 dataset_id，选择后回到该文件取数，同名字段不会跨文件混用。后续导入使目录版本发生变化时，“全部”目录也会重新加载。

搜索只提供真实字段字面召回，不用匹配结果代替模型选择业务口径，也不把不同文件的数值自动相加。

## 默认宏观知识库

原生服务按当前空间明确的 kind=macro 绑定返回默认知识库，并核验实际读取权限；不通过名称推断或连接旧研究台。当前空间的现有与后续工作台都读取这一共享来源。尚未初始化 Default 的空间继续使用已有显式初始化入口，不在 GET 请求中偷偷创建知识库。

主库与默认宏观库分别检查原件、确认状态和版本，分别复用签名只读索引，通过只读视图统一查询。宏观版本变化不会触发主库全量重建；权限、绑定或来源失效时拒绝旧数据。字段和来源证据标记实际知识库、来源角色及其版本，模型工具也能看到这些元数据。

原来旧研究库中的宏观记录需先保留真实原件与审计证据，再经正式知识库上传、结构化预览与确认流程纳入 Default；运行时不以旧研究库补值。迁移只使用原登记单位与原始数值，不隐式套用旧展示缩放；未采集的登记不生成占位观测。实际迁移及数据比对结果见本轮运行验收记录。
