# 按真实数据绘图与 PPT 原图预览

普通研究对话提供 `render_chart`，用于从本轮已经成功读取的数据生成折线图、柱状图或散点图。它不调用图片生成模型，也不执行模型提交的代码。

模型先调用 `inspect` 查看实际数据来源句柄、列索引、单位、行数和完整性，再通过 `render` 选择来源、X/Y 列及图型。数据来自已授权的结构化查询结果或实际读取的文档 Markdown 表格。目录、字段说明、失败查询和模型自行编写的数字不能充当数据源；修改数据后旧来源句柄失效。

图表保持实际行序、原值及缺失断点，不填零、平滑或推造日期。时间轴要求原表实际 ISO 日期；缺少日期时使用原有类别标签。不同单位不自动合并或换算。图内仅保留标题、坐标、图例及必要的单位/部分范围标注，不嵌入解释段落、原始数据表或技术JSON；来源与核对数据保留在工具审计中。超预算时明确失败，不用截断样本冒充完整走势。

图表以确定性PNG图片保存到回复附件，可直接预览并下载。保存沿用现有资源目录、消息归属和权限下载；文件归实际发问者的会话，共享智能体的执行空间不改变附件归属。同一工具执行重复交付复用既有附件，删除后的附件不会因重试复活。生成成功与否以实际保存的附件为准。历史HTML附件保留原样。

模型依据完整请求选择`delivery_mode`：默认`chart_only`只回复图片，不追加过程、解释、统计或建议，也不自动附加分析面板。用户明确同时需要文字分析时才用`chart_with_analysis`，保留相应分析展示；失败和无数据不伪装为成功图片。

该功能是对真实数值的确定性重绘。查看报告原有图表仍应打开来源预览，插画生成仍由单独的 `generate_image` 能力处理。

PPT 来源预览会将原文件内部的 OLE 缓存图片提升到浏览器可显示的预览副本，不打开外链或执行嵌入对象。解包、排版与显示在浏览器完成；EMF/WMF 仅在对应物理页进入视口或被引用时，通过现有受保护接口按源 SHA、物理页和媒体 part 转成 PNG。浏览器内矢量图请求统一限制为两个并发。替换直接作用于原图位置，保持页面布局和滚动位置；原文件字节及知识解析结果不变。

同一浏览器页面使用64MiB、128项、10分钟有效期的内存缓存，保留成功加载的原文件、预处理数据和PNG；关闭预览只释放该实例的object URL，重开可以复用字节。引用面板还会保留当前单份PPT的排版DOM，关闭时暂停媒体加载，重开仍先校验权限与文件版本；切换来源、回到引用列表、切换账号或离开当前会话时释放旧预览。每次打开先读取当前知识详情校验权限与文件版本，缓存还按登录凭据、激活空间、真实文件身份及源SHA隔离。失败不缓存，图像解码失败会淘汰相应PNG以便重试；切换来源或权限后，过期异步响应不能回填旧图。

关闭时已开始的至多两个共享转换请求可完成并填充缓存，其余已关闭视图的队列不再启动。缓存不写本地持久存储，刷新页面、超过有效期或容量淘汰后仍会重新请求；首次未缓存的矢量图仍由服务器转换，服务器已有独立的有界转换缓存。缓存命中不能替代每次打开的权限检查。

预览需要浏览器能计算原件 SHA（安全上下文，如 HTTPS 或 localhost），后端校验失败时不会用其它页或其它文件的图替代。实际完整性需检查图像解码和内容，不能仅凭页壳、logo 或 HTTP 200 判定图表显示成功。
