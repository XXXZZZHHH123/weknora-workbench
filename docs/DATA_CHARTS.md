# 按真实数据绘图与 PPT 原图预览

普通研究对话提供 `render_chart`，用于从本轮已经成功读取的数据生成折线图、柱状图或散点图。它不调用图片生成模型，也不执行模型提交的代码。

模型先调用 `inspect` 查看实际数据来源句柄、列索引、单位、行数和完整性，再通过 `render` 选择来源、X/Y 列及图型。数据来自已授权的结构化查询结果或实际读取的文档 Markdown 表格。目录、字段说明、失败查询和模型自行编写的数字不能充当数据源；修改数据后旧来源句柄失效。

图表保持实际行序、原值及缺失断点，不填零、平滑或推造日期。时间轴要求原表实际 ISO 日期；缺少日期时使用原有类别标签。不同单位不自动合并或换算。图内保留来源、原值核对表、未知单位和部分范围提示。超预算时明确失败，不用截断样本冒充完整走势。

图表以静态 HTML 内嵌 SVG 保存到回复附件，可点击预览并下载。保存沿用现有资源目录、消息归属和权限下载；文件归实际发问者的会话，共享智能体的执行空间不改变附件归属。同一工具执行重复交付复用既有附件，删除后的附件不会因重试复活。生成成功与否以实际保存的附件为准。

该功能是对真实数值的确定性重绘。查看报告原有图表仍应打开来源预览，插画生成仍由单独的 `generate_image` 能力处理。

PPT 来源预览会将原文件内部的 OLE 缓存图片提升到浏览器可显示的预览副本，不打开外链或执行嵌入对象。EMF/WMF 仅在对应物理页进入视口或被引用时，通过现有受保护接口按源 SHA、物理页和媒体 part 转成 PNG。每个预览最多两个请求，同一媒体缓存复用，切换来源时取消并释放。替换直接作用于原图位置，保持页面布局和滚动位置；原文件字节及知识解析结果不变。

预览需要浏览器能计算原件 SHA（安全上下文，如 HTTPS 或 localhost），后端校验失败时不会用其它页或其它文件的图替代。实际完整性需检查图像解码和内容，不能仅凭页壳、logo 或 HTTP 200 判定图表显示成功。
