# WeKnora v0.8.3 集成记录

日期：2026-10-15。

- 新上游正式版：[v0.8.3](https://github.com/Tencent/WeKnora/releases/tag/v0.8.3)，`3e22822c1d2397be730c458c7539d0eb8c113a24`。

纳入官方检索、图片与引用、工具目录、附件读取、模型管理、迁移和相关界面的更新。`structured-data/`、`commodity-research/` 的业务源码保持原样，不迁移或修改实际业务数据。

## 定制功能的兼容处理

1. 保留中哲物产导航、资料中心和商品研究入口。官方的动态工具目录同时提供结构化表格和商品研究工具，不让它们因前端改用后端目录而消失。
2. 保留统一问答取数、模型生成来源计划、同名来源澄清、文档 ID 边界和独立数值核验。官方检索的图片、输出预算、失败诊断与这些约束一起工作；未绑定来源时仍只向模型提供候选元数据。
3. 保留工作台按实际配置启用沙箱的行为及显式推理预算；集成官方附件读取与只读工具并发。
4. 保留 PPT 物理页、原始图片关系、OLE 缓存图表、EMF 文字与几何来源，以及转换资源限制。按每个实际图片位置和关系处理重复名称、复用图片及嵌套分组；图片失败不能串到下一张图，也不刷新外部链接。
5. 修复无文本冲突合并产生的重复引用组件初始化，补齐繁体中文的问答进度翻译。

没有增加按具体问题、商品、日期、文件或指标决定答案的分支。问答链路的既有审计边界仍见 [问题硬编码审计](QUESTION_HARDCODING_AUDIT.md)，本记录不对未覆盖的所有代码作无限范围保证。

## 数据库和发布配置

本项目已发布的 SQLite `000031_mcp_metadata` 与官方新分配的编号冲突。保留已发布迁移不变，将官方模型目录迁移移至 `000037`；官方重复的 `000034_mcp_metadata` 留作空操作，避免重复加列或回滚时删除既有 MCP 数据。新增从本项目 v31 升级并保留服务说明和工具目录记录的测试，同时验证新建数据库和其他历史版本升级。

生产文档解析镜像改为从本仓库 `WeKnora/docker/Dockerfile.docreader` 构建，避免发布时继续使用未包含定制页码和图表处理的旧官方镜像。镜像输入指纹包含解析源码、锁文件、构建文件和包目录，解析代码变化会触发重建。PostgreSQL 镜像随官方配置更新为 `paradedb/paradedb:v0.25.11-pg17`，对应官方扩展迁移。

源码合并和发布包生成不代表服务器已经部署。生产升级仍由运维按 [部署说明](../deploy/README.md) 手动执行，数据库升级前应保留备份。

- 前端：类型检查、生产构建通过；1186 项测试通过。官网文档目录按快照策略未纳入，因此官网源文档锚点检查 1 项跳过，文档 URL 映射检查保留。
- Go：`internal/agent`、`internal/agent/tools`、`internal/modelcontext`、`internal/database`、`internal/handler/session` 套件通过。工作台配置、历史上下文、MCP 和商品研究注册回归通过；模型更新接口回归通过；`cmd/server` 本机编译通过（不包含 anydoc 构建标签）。
- 文档解析重点测试：PPT 媒体、图表几何、PPT 转换、来源定位、并发和 Excel 样式修复共 64 项通过、7 项因可选运行环境跳过，另有 29 项子测试通过。

- 发布与同步工具：57 项测试运行通过，4 项既有跳过；同步元数据有效，已无待处理冲突。
- 结构化服务完整套件在 macOS 上为 390 项通过、19 项跳过；9 项失败和 8 项准备错误来自本机无法设置子进程资源限制。相关源码本次未变，没有把它们算作通过。

新增 CI 文档解析回归任务，并把数据库迁移检查纳入 Go 检查。Linux 镜像构建、服务器升级及真实模型对话验收需以对应环境的实际执行结果为准。本轮未上传业务样例、未调用在线模型作功能验收，也未更新本地容器或生产服务器。
