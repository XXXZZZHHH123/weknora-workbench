# 问题硬编码审计

## 2026-11-13 问答回归修复的增量边界

来源恢复依据本轮真实目录覆盖、字段绑定协议、已发现文档及实际读取状态。模型结合完整任务决定是否继续取证、读取哪种来源表示，以及是否分别报告多个有明确标签的字段；程序不按问题词、商品、文件名、日期或预期答案选源，不自动替换来源绑定中的字段 ID。导航进度只是有范围和遗漏标记的运行提示，不成为引用或数值证据。

来源探索累计三个真实原生工具批次后，可提前使用同一个单次模型检查预算。批次数只是检查时机，不是失败判定或固定换渠道条件；模型仍根据原任务、真实运行状态和可用能力决定继续或调整。提前检查会占用该轮原有交付范围检查，后续明确记录未重复检查，数字、引用和可选语义编辑器仍独立执行。恢复不重置迭代次数或权限边界。

该检查不以可选任务计划解析成功为前提；计划不可用时仍依据原请求、授权能力和实际执行结果判断。用户中途提出新要求后，从真实执行边界重新累计来源批次，不用空计划推断任务变化。来源检查仅遇到响应协议错误时，可在原12秒、768生成token总预算内修复一次；传输、取消和非正常结束不重试，无效结果不成为放行决定或来源事实。真实usage与无usage情况下的保守字节计账、协议错误分类及失败记录均保留，不增加问题/商品/文件选择分支。

引用视图冲突的恢复仍校验真实分块、原件版本和显式页码范围。PDF 物理页来自同一已授权文件的真实表格单元格来源。SQL 列操作元数据来自实际语法树，列别名不能把末条观测改成最大值。有效原始值是否参与统计由模型依据用户要求与来源质量决定，不按验收数字排除异常值。

可选答案编辑器读取完整的当前引用视图及实际结构化结果，保留局部视图的范围。原本没有可用审核输入且回答无引用标记时，可提供本轮真实读取的全部正文视图；不采样正文，共用重复元数据，明确标记省略的定位摘录，不能以该省略反证事实不存在。输入预算不足时明确记录未检查。编辑仅接受唯一、精确、无重叠的片段替换，之后重新校验来源与数字。格式或定位错误最多修复一次，共用原来的时间和生成 token 总预算，不将无效修改视为已经纠正。单位、时间顺序、比较排名和版本权威关系由模型对照实际证据判断，不增加特定问题的答复分支。

预算内的正文共享只合并逐字相同的传输内容，各文档身份、版本、页码、局部范围与引用条目仍分别保留，不合并来源权威。结构化行视图可利用同一编辑器总输入预算中的剩余空间；仍须包含全部执行结果行，不能按问题或答案筛选行。已有一次协议修复可使用绑定原候选的短段落标识定位原字节区间，拒绝未知标识、跨候选标识、重叠或整答替换，不引入模糊定位或额外模型调用。

PPT 预览按实际资源配额、时间预算及原始部件哈希处理，缓存不替代来源授权，延后预览保留原始媒体和页码绑定。联网有限重试只依据传输错误、状态码和剩余时间，不改变业务答案或供应商配置。

旧入库漏图的恢复从当前授权原件的真实物理页关系生成有界目录，不按正文中的文件名猜归属。原件媒体选择器与已存资源引用分开，每次读取重新核对知识库、当前文件及媒体哈希、页和部件关系；不伪造资源记录、不修改历史分块。目录只提供导航，只有实际通过校验的像素或几何读取可以成为图像依据。

原件媒体进入审核视图时继续核对规范选择器、当前知识库和文档、物理页、部件、原件与媒体双哈希，以及实际读取、目录和分块见证。渲染后的像素哈希与原始媒体哈希分别校验，不混用。独立成功的像素读取不因可选几何分析尚需模型选择图例而失败；后者只返回真实图例导航，不自动选择曲线，也不授予几何数值依据。目录完整性仅描述本次已验证物理页的原件图片，与正文分页完成状态分开。

未解决的版本冲突也不能由模型自拟使用目标或较大、较小的数值转成采用某版的建议；真实用户目标与来源证据仍由模型判断。此项为通用语义要求，不增加问题匹配、预期数值或答案特例。

这次检查限于新增和修改的路径。私有真实回归保留失败、附加错误及修复后的结果；离线检查、模型接受、实际内容正确和发布状态分别记录，不宣称整条历史链路或任意问法已经完全通过。

## 2026-11-11 大目录发现与来源读取的增量检查

本轮目录索引只保存真实发布元数据，并按真实标题、字段及模型给出的检索词提供有界候选。字面匹配仅用于召回和排序，不决定业务意图、口径或答案。投影保留真实数据集、字段、版本及分页身份，并明确截断范围；模型继续依据完整问题选择来源并提交只读查询计划。多字段同范围查询使用既有一次 SQL 能力，程序不会按问题文本合并查询或自动选择同名字段。

原图派生预览须通过持久来源绑定，或与指定原件部件的精确重渲染结果对应；保留权限、文件及部件哈希校验，不以视觉相似或商品专属规则放行。工作簿读取仅在请求单元格确有公式时补开缓存值视图，数值、来源与单位校验不变。模型协议兼容仅处理明确的传输错误和有界空输出，不生成固定业务回复。

网页模型视图按原文 Markdown 结构保留分块及字符位置，日期和业务事实仍由模型理解，不以日期正则或问题关键词推断归属。结构化答案的可选纠正沿用单次预算，模型提出精确片段替换，程序验证匹配范围及既有数字、来源和引用约束；不得通过纠正改写已批准的来源证据。纠正视图因预算省略结果行时，跳过这次可选纠正并保留已校验候选，不能将未展示的行当作不存在，也不为补齐审核上下文追加检索。

回归样例及预期值仅进入隔离测试和私有验收记录。本节说明新增路径的审计边界，不代表历史全部路径或任意问题已经完全符合要求；实际模型正确性、用时与发布状态仍需独立验收。

## 2026-11-04 问答检索与数据绘图的增量修复

本轮只处理上下文来源发现、二维表绘图、PDF SQL 输出来源依赖及交付核验。模型根据完整问题与会话决定搜索语义、恢复来源、行列方向、指标、坐标类型和交付要求；没有按问题词表、业务指标、文件、时期或预期答案添加生产分支。

程序验证当前权限、实际工具来源、单元格坐标、单位一致性、分页范围、SQL 语法树字段依赖及真实附件，并执行确定性映射/计算。内部来源行 ID、SQL 语法枚举和错误协议属于技术身份与安全校验，不据问题文本决定业务意义。常量维度标签与伪造观测明确区分，SQL 执行成功不能自行授予源表数值权威。独立绘图语义核验与公开的执行成功状态分开，私有凭证只复用已核验的精确交付。

新增测试使用隔离的合成表、错误映射、来源依赖旁路与等义追问。真实模型验收由显式私有配置启用，既有模型失败也保留，不向业务知识库写验收样例。验证范围及绘图协议见 `DATA_CHARTS.md`；此增量检查不等同全仓重新审计或任意问题均已正确。

## 改造边界

问题理解、否定、比较、多来源、口径和回答格式进入统一的模型计划。程序验证授权、真实 ID、计划结构、来源元数据、数值和计算结果；保留原文件与单元格来源。

删除来源保护而没有替代的计划/证据校验，会重新允许随意选择同名列或混用报告。此前先撤回直答捷径；本轮已将下面的历史来源策略迁到模型计划与实际来源校验，没有引入替代关键词分类器。

协议枚举、权限角色、分页/资源限额、物理单位精确转换、JSON schema、显式日期参数合法性检查不是问题到答案映射。测试中的固定文件/数值属于隔离验收事实，不进入生产问答。

用户约束已写入仓库根 `AGENTS.md`，后续实现和审查必须遵守；没有逐项改造并验证之前不能宣称整条链路已完全清理。
