## 改造边界

问题理解、否定、比较、多来源、口径和回答格式进入统一的模型计划。程序验证授权、真实 ID、计划结构、来源元数据、数值和计算结果；保留原文件与单元格来源。

删除来源保护而没有替代的计划/证据校验，会重新允许随意选择同名列或混用报告。此前先撤回直答捷径；本轮已将下面的历史来源策略迁到模型计划与实际来源校验，没有引入替代关键词分类器。

协议枚举、权限角色、分页/资源限额、物理单位精确转换、JSON schema、显式日期参数合法性检查不是问题到答案映射。测试中的固定文件/数值属于隔离验收事实，不进入生产问答。

用户约束已写入仓库根 `AGENTS.md`，后续实现和审查必须遵守；没有逐项改造并验证之前不能宣称整条链路已完全清理。

### 真实对话验收与运行修复

仅创建标注为验收的聊天，未上传新业务文件、未写入固定问答数值。七个真实模型对话及原文件独立核对共 29 项检查通过：

- 快速问答、智能推理、表格数据分析均取得同一版本 U100 的 11902 元/吨，日期 A100 为 2016-04-07，公式 =T80。逐项核对原件 SHA256、实际返回行及缓存值；不是仅比较答复文字。
- 否定其他来源后仍取得正确字段；明确比较两个来源时分别保留 C100 的 12055 和 U100 的 11902，未合并或平均。
- 裸指标名由真正模型调用生成四列及各自公式/表头来源的澄清，不替用户选列、不输出固定澄清。末次完整对话约 78.3 秒；该例仍有多轮模型/原件核验开销，不能把旧 0.74 秒或回退后的 13.6 秒当作当前耗时。
- 周报问题由模型提交实际文件及日期证据的来源计划，仅读取目标报告物理第 12 页；答复红色 2401、约 210 元/吨（170–250 估读）、自身端点排名第 3/9，并明确不是同日精确截面。回答明确原文件、页和图源；有 chunk 引用时验证真实归属，未把其他报告的同名图当依据。

运行中发现并修复的通用问题也已纳入测试：

1. 模型澄清可暂不选择字段；空 selected_ids 只在 clarify 且完整考虑实际来源、提供模型澄清文字时有效。resolved 的空选择仍拒绝，未执行取数。
2. 大目录先按完整实际来源摘要交模型规划范围，再筛选压缩的真实字段元数据，恢复选中字段及全部相关同名来源的完整深层证据。真实 3128 个字段/视图由模型选择实际范围，47 字段分两批；最终绑定保留全部四种来源，未按问题词选择来源。
3. resolve_fields 区分可信原问题/用户及助手角色对话与主模型技术子任务；子任务的日期不自动当作用户条件。去掉时间 evidence 的程序覆写，模型须引用真实用户原话，错误走通用修复。
4. 数值校验取完整成功运行结果的规范 Data，展示文本格式化/截断或无效 JSON 不再造成元数据数字误拒。只接受已执行的结构化读取结果，schema、失败工具和文档嵌入 JSON 不成为计算依据。隔离的真实旧失败记录重放通过。
