# 研究逻辑检查与保存

入口：研究判断 → 管理研究逻辑 → 导入与分析 → 分析原文。

## 核对与保存

模型分析完成后，按研究结构直接展示内容。普通说明和通过校验的条件自动接收为草稿内容；“已解析”不表示有人逐条确认，也不表示观点已经被事实证实。仅实际有问题的字段标红，提示缺什么、如何处理；可切换为仅看问题。

原文全文保留，对照入口为可选操作。时间维度、研究说明等文字不要求再选逐字依据；量化条件缺少可靠引文时才提示补充。已有摘录与模型归纳分开展示，不把归纳文字伪装成原文。

选择指标、采用原文或修改记忆选项后，立即校验并更新私有预览；无需逐条点确认。失败时保留输入、在对应字段提示，尚未同步成功的修改会阻止最终保存。只有“保存草稿”会新增研判版本，不自动生效。

指标搜索覆盖整个授权目录，不限于模型当次候选。新来源协议使用服务端分页，默认每次 20 项、最多 50 项；不加载观测值。确认和搜索会重新核验来源权限、目录版本及研判版本，来源变化或预览过期后须重新分析。旧 v1 来源适配器的内部全量目录传输仍存在，本次没有宣称该旧协议已经分页化。

## 条件与数字

绑定成功表示选定了数据锚，并不表示观点已成立或规则已经触发。目录单位未确认时，仅支持描述性引用；阈值和证伪仍需通过真实 ID、单位、原文摘录及数字校验。

解析后的条件单独展示比较方式、数值、单位、连续期数和证伪对象。证伪对象指原假设失效的一方，不代表触发后的价格涨跌方向。

自动接收仍须满足原有协议校验。缺少数字依据、错误单位、无法表达的动态计算条件不能绕过校验；未通过的候选可保留为文字，不能作为量化规则执行。普通说明不因缺少摘录而成为问题。

本版不支持在确认页直接修改规则数字、比较方式或证伪对象。需要修改时返回原文，准确写明数字、单位与条件后重新分析；不会由程序替用户补数或修正业务含义。

## 绑定选择与审计

“记住此绑定”默认不勾选。仅在用户主动选择并通过校验时保存该选择；下次可主动启用曾用建议。启用后逐条校验并采用相容选择，失败的建议留在红框中且阻止保存，不会把界面显示的建议悄悄保存为另一指标。

记忆按账号、空间、研究台、品种、原文和条目上下文隔离。指标元数据或来源授权签名改变后不复用旧建议；不会按问题关键词、名称相似或商品名称自动决定绑定。

哪些结构允许绑定由协议规定，实际推荐的指标由模型根据完整原文和授权目录生成。程序检验真实 ID、单位、数字和引用，不通过业务关键词替代模型选择。可选数据锚允许为空；必需的规则引用缺失时才作为问题处理。

绑定随具体研判版本保存，版本归属于已验证的研究员；引用记录通过研判 ID 关联。一个账号选了指标，另一个账号保留文字，分别保存真实 ID 与空引用，不修改公共指标或观测值。个人记忆也不作为整个工作台的公共映射。

旧模式同一账号的多个研究台仍共用版本分配与并发基准，因此另一台保存后可能需要刷新当前预览；比较内容已限定为本台自己的最新版本。本次不调整旧模式的版本启用约束，不能将它等同于各台使用独立成果库。

私有审计保留模型原始候选、修复历史、人工动作、真实指标和所选原文，页面不展示这些技术记录。预览有效期为 15 分钟，服务重启也会使尚未保存的预览失效；已保存研判不受影响。多个标签页同时修改时，旧版本的确认或保存请求会被拒绝。

## 本次验收范围

后端使用合成资料、模型替身和临时 SQLite 验证协议、权限、事务回滚及数值边界；浏览器验收使用真实模板、脚本与确认 API。没有代用户调用配置模型、保存真实业务研判或激活任何版本。实际业务资料仍由用户自行分析验收。
