# 研判、研究方案与日报周报的复用边界

工作台功能与品种资料分开维护。业务研究文字、原件、观察区间、规则值和真实指标 ID 属于用户的知识库或研究版本，不放入通用问答、来源选择和报告生成代码。导入其他品种时重新读取当前授权目录、核对单位并建立绑定，不能直接复用另一知识库的 ID。

## 从研究材料到可计算条件

1. 研究员提供完整研究材料、方法准则和明确的品种代码。首次导入不按工作台名称猜测品种；已有研究默认使用当前账号最近明确保存的品种。
2. 模型阅读完整原文及真实授权指标目录，提出主矛盾、短线边际、指标绑定、阈值、优先级和证伪条件。目录字面搜索只提供候选证据，不能替模型决定业务意图或权威口径。
3. 程序验证真实 ID、来源版本、单位、原文规则依据、有限数、规则表达式及读取预算。没有明确单位、同口径数据或数值依据的项目留作待确认文字，不能变成自动执行规则。
4. 用户预览 Markdown、指标绑定与版本差异，再确认保存草稿。人工编写的结构化 JSON 走独立的身份与结构校验、预览和确认通路，不调用模型，也不把原文观点当作已验证事实。

人工稿不接受用真实指标 ID 为未经取数核验的事实数值背书。阈值及证伪是研究者设计的假设，必须与指标单位一致；原始事实来自知识库正式导入的数据。当前受限成员不能通过研究导入扩大自己的来源或编辑权限。

当前可计算规则是单指标阈值比较、区间，以及 `value` / `change` 比较连续满足若干有效观测的条件。“边际焦点”保留描述和指标引用，不是任意自然语言公式引擎；跨指标供需平衡等复合条件需要先定义有单位和口径的派生指标，再绑定规则。

## 研究方案与交易计划

研究方案卡保存研究假设、观察依据、触发条件、失效条件、复核日期和原始资料。它是个人研究记录，可以手工填写或导入，不会自动从文字推断数值条件或下单。关联资料用于追溯，不表示正文数值已逐项核验。

交易计划使用另一套严格结构：具体合约、报价指标、方向、入场/目标/止损、证据、风险参数和实际成交。合约乘数、最小变动价位、交割年月和规格来源须由当前绑定的明确元数据提供；模型不能猜测或改写。既有单品种适配器保留兼容，新品种不继承其乘数。当前执行与盈亏流程仍限定明确的人民币/吨报价，其他计价体系不能直接套用；研究、条件监测与报告不因此固定为某一品种。

## 日报与周报

报告的数据部分由确定性程序组装，不在每次打开页面时让模型重新编写观点：

- 日报以所选日期为截止，展示必要指标及有效观测变化、已保存的研究逻辑、研究方案与交易计划、缺口和待复核事项。
- 周报汇总周一至所选日，比较区间内有效首末观测，展示期间记录的策略事件和研究版本变化，并整理下一次需要验证的条件。
- 百分比的起值为零、口径发生变化、数据不足或来源无权限时，保留原因，不补零、拼接日期或将缺失解释成条件未触发。
- 观点来自已保存的人或模型研究内容。报告不会因为缺少分析内容就编造价格区间、交易事件或新的边际结论。
- 页面与 Markdown 以可读章节呈现，完整输入和来源留在审计折叠区。知识库导出继续核对目标文件夹、写权限与来源，保留幂等和审计。

当前保存的研究逻辑用于回放时，必须明确属于“以当前研究版本读取所选历史数据”，不能声称在那个历史时点已经可知。冻结归档保留生成时记录，不因后续导入或逻辑修订重算。

报告另有只读规则试算：用保存版本中的绑定、阈值和证伪表达式计算选定日期的结果，并列出实际参与计算的观测日期。草稿也可试算，但会标记为草稿；试算不激活研判、不写入正式信号、不生成交易或改动冻结归档。研究方案卡中的自由文字仍是待人工复核的条件，不会由此变成可计算表达式。

## 容量与隔离

工作台按页面已保存的真实指标绑定获取必要观测，不因新增一个品种而预加载整个知识库。报告窗口必须满足规则连续期数，再应用指标数与总观测预算；展示点数不能截短规则需要的窗口。指标选择器的元数据接口保留来源、权限、版本和分页，不额外生成它不需要的表格 HTML。问答侧栏首次唤起时才加载其重依赖，收起后的会话状态保留。

本文件描述本轮相关路径和明确边界，不代表整个历史系统所有单品种限制或问题硬编码已完成清理。历史审计仍见 [问题硬编码审计](QUESTION_HARDCODING_AUDIT.md)。
