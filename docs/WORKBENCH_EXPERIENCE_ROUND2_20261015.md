# 研究工作台体验修复与验收 · 第二轮

本轮继续 `feature/research-workbench-templates`，沿用原研究台布局、主题和输入框，没有建立新的研究事实库。原件与已确认结构化事实以绑定知识库为准，工作台数据库继续保存研究成果。

## 完成的功能

1. **连续区块导入**：修复确认按钮跨刷新遗留禁用、未导入区块草稿丢失、按数组位置误判已发布区块。浏览器覆盖连续三块、刷新后续导和区块重排；真实 DuckDB 验证 2→4→6 条记录、零值和来源单元格。
2. **空对话历史**：服务端列表、搜索、计数和项目计数只收录有未删除用户消息的会话。草稿仍可进入，首次真实消息落库后入历史，清空后移出。前端防止较早详情响应在清空后复活历史行。
3. **研究问答**：删除顶部重复知识库说明，在原输入框默认 @ 当前绑定知识库。模型和提及是局部状态，收起再展开保留对话草稿，不污染主问答设置。
4. **切换性能**：父页面先交换登录 Cookie，随后直接进入指定工作台；视图切换不再经过 bootstrap 或重新登录。总览复用同次读取的来源与计数。原生抽屉打开时隐藏引导卡，非首页不默认显示引导，防止遮住应用按钮。
5. **产业图生成助手**：复用已有 Markdown 编辑与动态画布。支持图片、知识库图片/文字原件和结构说明，选择原有配置的对话模型。模型理解完整资料并选择真实指标，程序校验 ID、绑定知识库和来源版本；生成只产生待确认草稿，应用时再次核验。大目录先由模型提出检索词，字面匹配只召回证据，最终绑定仍由模型决定。无指标可绑定时保留未绑定节点。
6. **日报归档**：既有个人简报和当日真实数据快照可导出到绑定知识库的已有文件夹，默认根目录。普通 Markdown 沿用原生解析；返回真实文档链接。相同内容、目录和日报复用原文档；解析失败也返回原文档处理入口，不反复创建失败副本。
7. **目录留白**：文件夹区域增加 12px 上边距，保留原页面结构和其它间距。
8. **CLI 委托试验**：分别执行一次隔离长任务，完整候选经静态审查、断网测试和独立边界验收，结果见下文。

## 数据装载优化与边界

每次读取仍实时验证账号/工作台/知识库权限、完整原件目录、原件哈希、工作表确认记录与结构化版本。版本一致时可复用只读 SQLite TEMP 投影；版本变化、来源撤销或核验失败会失效，禁止返回旧副本。缓存不含问题、答案、业务意图或登录令牌，不提供问答捷径。

逐行重复的完整证据对象改为紧凑 TEMP 记录，共同来源元信息按指标共享，查询时还原原件、单元格、原始值和版本。实际只读抽样为 38 个指标、107825 条原始观测，其中 99329 条有有效值和日期；投影约 46.78 MiB，临时数据库的持久事实表为零。独立测得装载冷读 6275.6ms、热读 39.4ms，热读仍发起原件目录与版本核验。这是装载环节耗时，不是整页浏览器耗时。

每个保留连接预算 64 MiB，最多保留四个引擎，复用期五分钟。过期在下一次访问时清理，不声称闲置到期立即释放内存。并发冷读仍可能分别构建投影；两次 107825 行合成并发测试读取 22 页、RSS 峰值约 388 MiB。未为此强制单连接，避免异步嵌套会话死锁。超出预算不保留投影；不存在失败时旧数据回退。

目录按原生分页完整核验，普通日报文档不占结构化原件额度。边界为 10000 条目录、128 份结构化原件、200 万条观测；超限明确失败，不返回部分事实。生成助手候选目录和图片大小有界，候选截断会提示，不能推断为完整搜索。
