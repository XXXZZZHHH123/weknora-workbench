# 通用工作表解析与确认（第二阶段）

## 已交付的流程

上传 `.xlsx` → 扫描全部工作表的表头样本 → 识别布局 → 自动处理结构明确的表 → 全量逐行校验 → 保存可查询版本。复杂表保留在“待确认”。用户可编辑映射、预览结果、确认并保存模板；下一份同名且表头结构相同的表可自动复用。

解析、校验和入库在本机运行，不调用 Embedding。点击“AI 辅助生成建议”时，才会将有上限的表头与样本交给已配置的百炼聊天模型；模型建议不会自动批准或导入。

## 独立小表更新（2026-09-28）

每块可选择“每行有日期”或“整块共用一个日期”，并设置类别列。预览按区块展示数值、日期、类别及各自来源单元格。

“2018年抛储”已针对原表布局生成三个待确认区块：日度主表 A5:AF147、库存 AG90:AG147、共用 AG15 日期的成交小表 AG17:AM19。日期或口径不明的区域单列待检查，不自动借用左侧主表日期。

普通日期表仍可复用相同结构模板；独立小表共享日期模板仅复用完全相同的源文件，文件改变后需要重审。保存时记录区块表头，并在解析时再次核对。详见 ../results/2018年抛储分区验收.md。

## 网页操作

1. 打开 http://127.0.0.1:18082 ，使用现有 WeKnora 测试账户登录。
2. 本次文件已经扫描，无需再次上传。在“工作表识别与确认”选择扫描记录和工作表。
3. **已导入**：可直接在下面搜索指标并查询，也可在 WeKnora 的“棉花数据分析（结构化）”智能体提问。
4. **待确认**：查看原表样本，检查日期列、表头行、数据范围、各指标名称与单位。单位不清楚就保留为空。
5. 点击“预览解析结果”，先核对结果和异常提示。只有确认口径正确后才勾选并点击“确认并导入新版本”。
6. 保存模板后，新文件的工作表名称、表头内容、颜色、格式及合并范围必须匹配，才会复用。表头变化会重新进入待确认。
7. 需要帮助识别时，可用“AI 辅助生成建议”。该功能可能产生少量聊天模型费用，仍需预览和人工确认。

不要将同一大表再传入普通知识库来使用这个功能；WeKnora 原生知识库上传仍然走原来的切分和向量化流程。

## 数据规则与边界

- 每个并排数据块使用自己的日期列，上层指标名称保留原单元格位置。
- 完整日期支持真实 Excel 日期及明确的日期文本；Excel 日期序号须显式指定。年份、月份、跨年年度矩阵本版不强转为某一天。
- 同名指标必须通过指标名称或维度区分。USDA 表依靠颜色区分年度，不能忽略颜色后直接回答“产量”。
- 重复日期、非日期数据行、无可用记录会阻断该表发布；已有数据版本保持有效。
- 只使用原文件保存的公式结果，不重算、不连接 Wind；错误、缺失、有效零分别处理。
- 图表和图片仅统计数量及所属工作表；尚未提取图表数据引用，也未做视觉识别。
- 原文件和旧数据快照保留；确认会生成新快照，预览和模型建议不会改变可查询数据。
- 只向 LLM 开放目录、查询和受控差值等 4 个只读工具；导入和确认属于管理页面。

## 技术实现

Python / openpyxl 扫描与确定性解析，DuckDB 保存和查询，FastAPI 管理接口，原生 HTML/JavaScript 工作台，MCP 接入 WeKnora。聊天模型沿用百炼配置。

`scanner.py` 负责布局和结构指纹；`generic_parser.py` 负责校验与解析；`imports.py` 管理扫描、确认、模板和不可变版本；`store.py` 提供确定性查询；`server.py` 提供登录、管理与只读 MCP。

扫描记录保存在 `data/imports`，模板在 `data/templates`，已发布版本在 `data/datasets`。同一文件重复上传会复用；发布中断后可以重新上传重试。后台任务状态仍在内存中，重启后查看扫描记录及版本列表确认结果。
