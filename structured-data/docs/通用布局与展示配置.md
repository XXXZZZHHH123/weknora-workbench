# 通用布局与展示配置

## 配置页面名称

编辑 `data/workbench-config.json`：

```json
{
  "title": "结构化数据工作台",
  "workspace_label": "Excel 数据管理",
  "agent_name": "表格数据分析（结构化）",
  "weknora_url": "http://127.0.0.1:18080/platform/agents"
}
```

刷新网页即读取展示设置，无需改 HTML。更改 agent_name 后运行既有 `scripts/register_weknora.py --apply` 同步自有智能体名称。此文件仅用于展示，不放账号或模型密钥。公开接口 `/api/ui-config` 只返回上述四个字段，链接仅接受 HTTP(S)。

## 支持的布局

| 排列 | 时间模式 | 数据含义 |
|---|---|---|
| 记录表 | date / excel_serial / custom | 每行明确日期；custom 额外填 date_format，例如 DD/MM/YYYY |
| 记录表 | shared_cell | 共用 date_cell 的日期；可选 date_format；可按类别分系列 |
| 记录表 | none | 没有时间字段；保留来源行和可选类别/编号 |
| 记录表 | period | date_column 读取原期间标签，保存为 period；具体日期为空 |
| 横向矩阵 | layout=matrix, date_mode=period | row_label_column 指向指标名；columns 配置数值列和 period 标签；row_rules 可配置每行的名称和单位 |

矩阵发现规则基于连续的明确期间表头、行名称和数值区域，不依赖工作表名称。全部候选保持待确认，最多检查前 200 行及 512 列来提出矩阵候选；解析覆盖用户确认的明确范围。未覆盖部分不会自动纳入。

无日期、期间、矩阵、共用日期区块必须明确结束行。矩阵列期间不得重复，相同年度的多个预测版本需不同标签。颜色不能自行变成年度标签。矩阵行名重复会阻断导入，需要拆区块或明确名称。

新快照增加 nullable date、period、period_cell、metric_cell；旧快照按旧列结构继续只读查询。无日期记录按来源单元格区分，禁止推测 latest。period 查询精确匹配原文，未知标签返回 no_data；不同期间的数值统计须先限定 period。

复杂布局模板绑定源文件内容；文件变化后重新确认，防止中部表头和年度版本悄悄错位。预览不发布，确认才生成新数据版本。

## 仍有边界

本版处理数值字段及其维度，纯文字表、图片识别、复杂合并表头的完整语义、仅凭颜色表达的年份、无明确信息的单位仍需进一步处理。旧棉花专用规则作为兼容适配保留，界面及通用矩阵/日期/无日期解析不依赖它们。

测试和真实文件结果见 `results/通用表格与USDA矩阵验收.md`。
