# 结构化数据工作台

在 WeKnora 基础上新增的 Excel 数据服务。数据导入和计算在本机完成，通过 MCP 将查询结果交给现有聊天模型，不对数值做逐条向量化。

**0.3.0 更新：**界面通用化并支持展示配置；新增无日期记录、手写日期格式、期间标签和横向年度/版本矩阵。USDA 原表已生成待确认矩阵并通过真实预览。当前自有智能体名称为“表格数据分析（结构化）”。下文旧棉花试点名称与数量属于历史阶段记录。见 [更新验收](results/通用表格与USDA矩阵验收.md) 和 [布局及展示配置](docs/通用布局与展示配置.md)。

## 增量导入与版本展示（2026-10-13）

确认工作表时只解析新增或修改的表，未修改的工作表复用已有数据库；记录和质量问题通过磁盘流写入。保留原文件、公式缓存、单元格来源与不可变历史快照。默认显示当前业务文件，历史记录按新增工作表或映射变化展示，验收样例在业务界面隐藏；相同文件、相同映射复用已有版本，普通对话的默认结构化目录不包含开发验收样例。同名指标按原表列区分，不合并数据；AI 辅助沿用模型的思考设置并保留全部原列，见 [导入恢复说明](../docs/WORKSHEET_IMPORT_RECOVERY.md)。验证结果及边界见 [增量导入记录](../docs/INCREMENTAL_EXCEL_IMPORT.md)。

## 最新入口（2026-10-11）

聊天现在由主模型理解本轮需求并自主组织步骤：解释已有结果时可直接回答；需要数据时按需检索真实字段、查询记录，或用 `analyze_table` 在隔离输入上执行只读 SQL。`resolve_fields` 保留为可选的语义绑定和常见查询工具，不再是每轮必经入口；拿到一个查询结果也不会立即结束整个回答。程序负责执行、权限、来源与数值检查，不按问题关键词决定意图。最终正文与原表计算依据分别展示，追问来源、日期和算法不会被上一轮结果卡片替换。

最新架构、已发现问题、原表独立核对及运行限制见 [模型自主分析验收](docs/AGENT_HARNESS_EVALUATION_2026-10-11.md)。2026-10-10 的 [历史评估](docs/REAL_USER_EVALUATION_2026-10-10.md) 保留此前失败证据，不能当作当前版本的完整验收。

[在 WeKnora 内打开结构化数据工作台](http://127.0.0.1:18080/platform/structured-data)：复用 WeKnora 登录。AI 建议与字段理解模型可在工作台右上角修改。代码主包为 `src/structured_data`，服务名为 `structured-data`；详见 [统一工作台更新与运行说明](docs/统一工作台与通用解析更新.md) 和 [逐题验收](results/统一工作台验收.md)。

## 网页操作

Docker 和两个服务运行后：

1. 打开 <http://127.0.0.1:18082>，使用原来的本地 WeKnora 邮箱和密码登录。
2. 已导入本次源文件，可直接选择最新版本、搜索指标、点击“选择”和“查询”。
3. 换文件时，使用此处“扫描并导入”；上限 100 MB。待确认表可查看样本、预览、确认并保存模板。
4. 打开 <http://127.0.0.1:18080>，进入“智能体”，选择 **棉花数据分析（结构化）** 并新建对话。
5. 提问时明确合约、指标和日期，例如“2023年9月22日 CF.CZC 的收盘价是多少？请给原单元格。”

首期服务只允许配置的试点租户登录。管理页与 WeKnora 使用同一账户，但各自建立登录会话。没有修改原来的知识库上传逻辑：从普通知识库上传 Excel 仍会走原解析流程。

## 数据范围和限制

- 期货的四类指标各用自己的日期列。CF09M 结算在 P 列，不能错取 Q 列。
- 仓单源表日期延伸到 2023-09-25，但主指标最新有效值是 2023-09-21。空白不能当零。
- 平衡表仍仅 A:Y 主区块；其右侧独立区块尚未导入。当前其他工作表的范围以扫描状态和最新数据集报告为准。
- 仅来源明确的单位自动采用；例如仓单 AF:AH 标注万吨。期货价格可做同一合约收盘/结算原始数值差，但不自动补造单位。
- 公式使用 Excel 上次保存的缓存值，未重算。部分原始 Wind 公式会将上游空值填零，服务不能逆向恢复这些空值。
- 每个快照保存原 Excel 副本。数据更新需要重新导入；没有自动连接 Wind 或实时行情接口。
- 只对“有日期的行”建立记录，不补造交易日或自然日。
- MCP 现有11项查询与分析能力；`analyze_table` 只允许单条 SELECT/WITH，隔离表仅装载所选文件版本、字段和日期范围，不开放原数据库、文件读取、联网或写入。输入最多50000条、16个字段；超过输入预算拒绝计算，输出截断明确标记。首期是本机试点，复用现有租户授权，不是完整企业数据权限系统。

### 2026-09-29 汇率同义检索与价格换算

指标目录支持识别货币对名称并提供汇率别名；别名只用于发现候选，不改写原指标、单位或数据。`list_series`的`sheet`严格限定来源，`context_sheet`仅优先排列上一问所在表。同名待确认工作表不再遮挡已导入的相关指标。

`convert_price`使用指定日期的价格和美元兑人民币汇率，以十进制计算美元/美分重量单价到人民币重量单价，保留双方原单元格。未知方向、缺失值、未知单位拒绝换算；结果不包含税费和通关成本。目前只支持USD→CNY，其他币种不会自动套用。

验收范围和模型账户阻塞见 [汇率同义检索与连续追问验收](results/汇率同义检索与连续追问验收.md)。

## 本地维护

项目位于 `/Users/mac/Code/weknora-workbench/structured-data`。服务发布在本机回环端口 18082，容器名 `weknora-structured-data`。现有 WeKnora 在 18080 / 18081。

启动前先打开 Docker Desktop。在本目录运行：

```sh
bash scripts/start.sh
```

只停止新增服务：

```sh
docker compose -p weknora-cotton -f compose.yml stop
```

开发运行：

```sh
uv venv --python 3.12
uv pip install --python .venv/bin/python -e '.[test]'
.venv/bin/structured-data --data-dir data serve
```

开发环境 Compose 将 src 只读挂载到容器；修改 Python 后需重启 structured-data。数据位于 data/datasets，服务密钥在 data/service-token（0600），不提交或发送此密钥。

验证：

```sh
.venv/bin/python -m pytest -q
COTTON_ACCEPTANCE=1 .venv/bin/python -m pytest tests/test_acceptance.py -q
.venv/bin/python tests/test_acceptance.py
```

仅在准备好进行少量真实模型调用时运行 scripts/test_live_chat.py；每次使用新的输出目录，不覆盖旧证据。导入和上述工具测试不调用模型。
